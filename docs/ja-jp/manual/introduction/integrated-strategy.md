# 自動ローグ

MAAはデフォルトでファントムテーマを選択しますが、`自動ロゲット` - `ロゲットテーマ`でターゲットテーマを変更することができます。

::: warning  
自動戦闘に関係するすべての機能には、以下の前提条件が必要です。これには自動戦闘と自動ローグが含まれますが、これらに限定されません。

- 少なくとも60フレームの**安定した**ゲームフレームレート
- タッチモードはMinitouch、MaaTouch、またはMuMu タッチ強化

:::

- ゲーム内で該当のロゲットテーマを端末に追加してください。現在は自動ナビゲートも可能ですが、長期的な使用可否は保証されません。
- **ターゲットテーマ**でない探索は事前に手動で終了してください。
- 設定では、テーマ、難易度、分隊、最初のオペレーターなどを選択できます。最初のオペレーターはデフォルトで第 1 順位のみで、`高度な設定` で第 2・3 順位を有効にできます。3 つの順位のオペレーターはそれぞれ職業が異なる必要があります。
- 募集は先頭の数ページのみを検索するため、希望消費の低いオペレーターは見つからないことがあり、その場合はデフォルトの方針に戻ります。希望消費の高いオペレーターを前に配置することをお勧めします。
- MAA は、サポートオペレーターでの開始を使用できます。まず ｢一般設定｣ → ｢最初のオペレーター｣ に目標オペレーター名を入力し、 ｢高度な設定｣ で各最初のオペレーターに対応するサポート使用のチェックボックスを有効にしてください。各順位ごとにサポートを使うかどうかを個別に設定できますが、第 1 順位でのサポート使用は ｢直接昇進｣ との併用はできません（直接昇進は所持オペレーターのみ対応）。
- 新しくインストールしたクライアントで初めてプレイする場合：
  - 難易度選択ボタンは表示されません。ゲーム内で一度手動で難易度を選択し、その後 MAA が自動で選択できます。
  - 大マップなどの画面に入ると新手のチュートリアルが表示されます。読み終わったら手動で閉じてください。

## 黒流樹海の初期報酬稼ぎ

黒流樹海で `初期報酬稼ぎ` 戦略を選択した場合、満足のいく開局を得るまで準備用の探索と目標の探索を繰り返します。以下の内容を設定できます。

- `狙う報酬` / `羽蛇の報酬`（後者は育成目標で `襁褓の羽蛇` を選ぶ必要があります）：両方でチェックしたものすべてが候補となり、目標の探索の開局でどれか 1 つでも出れば条件を満たします。
- `第1層の实托邦（第1層の種類）を厳選`：目標の探索で支援選択画面に狙う報酬が出たら、`初期報酬の選択優先順位` の順にカードを選んで第1層に入ります。第1層が实托邦ならテーマ画面へ退出してその探索を保持し、そうでなければその探索を放棄して準備用の探索をやり直します。難易度 6 以上が必要です。
- `初期報酬の選択優先順位`：ドラッグで順序を変更します。支援選択画面では、上から順に並んでいるカードを選びます。
- `第3層まで素早く飛ぶ`：準備用の探索は `特別行動分隊`・`攻守一体` と自分の機械師で固定して開局し、機械師だけを招集します。第2層では持ち込んだ構造性原理を使い、そのまま第3層へ飛びます。機械師の素質を全解放していないと飛べないため、チェックしないでください。

## 戦闘戦略

MAA はゲーム内のすべての操作を予め設定された戦略で行い、すべてのステージ戦闘は内蔵された作業ファイルを呼び出して行われます。該当ステージの作業が存在しない場合、賢くない汎用的な意思決定ツリーを使用して戦闘を行います。

詳細については[ロゲットプロトコル](../../protocol/integrated-strategy-schema.md)をご参照ください。

- オペレーターおよびレベルを自動で識別し、最適なオペレーターとスキルを自動で選択します。
- 商店のアイテムを識別し、より強力なアイテムを優先して購入します。

## 異常検出

- タスクに問題が発生した場合、現在の探索を自動で放棄し、再試行します。
- 戦闘時間が8分を超えると、すべての地上ユニットが自動で撤退し、10分を超えるとその戦闘を自動で放棄して時間の無駄を避けます。

同じ位置で何度も固まる場合は、ログとスクリーンショットを添付してIssueを提出してください。
