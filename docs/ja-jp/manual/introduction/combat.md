# 作戦

::: info UI 専用機能
本ページの一部機能は UI 層で実装されています（目標在庫、週次スケジュール、複数タスクの並び替えなど）。詳細は[始めに](../newbie.md#このドキュメントについて)を参照してください。

## 一般設定

- `理性剤使用数` と `割る源石の数`、および `周回数指定`・`素材の指定` はいずれもショートサーキット的なスイッチ（OR条件）です。これら3つの条件のうちいずれかを満たした時点でタスク達成とみなし、作戦を停止します。
  - `理性剤使用数` は理性を何回分補充するかを指定します（1回で複数本使う場合あり）。
  - `割る源石の数` は源石を何個割るかを指定します（1回につき1個）。倉庫に理性剤がある場合は源石を割りません。
  - `周回数指定` は選択したステージを何回周回するかを指定します（例：「15回周回後に停止」）。
  - `素材の指定` は特定素材を何個入手したら停止するかを指定します（例：「中級源岩を5個入手したら停止」）。2 つのカウントモードをサポートします：
    - `ドロップ数`：本タスク中の該当素材のドロップ数を目標とします。
    - `目標在庫`：[倉庫アイテム認識](./tools.md#倉庫アイテム認識) に保存された在庫データを参照し、設定在庫まで補充します。[データ更新](./user-data-update.md) または [倉庫アイテム認識](./tools.md#倉庫アイテム認識) で在庫データを取得する必要があります。このモードは UI により実装されています（Core はドロップ数モードのみサポート）。

- `素材の指定` と `ステージ` は互いに独立したロジックです。`素材の指定` は素材個数を達成条件に用いるだけで、該当ステージへ自動遷移はしません。
- `目標在庫` モードは[在庫維持](./depot-maintain.md)と開始時判定を共有します：タスク開始時に最新の在庫で不足分を再計算し、達成済みならそのままスキップします。また、このキューの実行中に既に戦闘が理性を報告しており、報告時刻から推定した現在理性（6 分につき 1 点・6 分未満は 6 分として計算、理性上限まで）がこのステージの 1 回の出撃に必要な最低消費未満で、このタスクに理性剤/源石の予算がなく、期限間近の理性剤も使い切っている場合（証明条件は[在庫維持 · 48 時間以内に期限切れの理性剤を使用](./depot-maintain.md#48-時間以内に期限切れの理性剤を使用)を参照）も同様にスキップします。いずれの場合も出撃しません。
- 複数の素材在庫目標を同時に管理したい場合は、[在庫維持](./depot-maintain.md) タスクを使用できます。複数の計画を順番に自動周回できます。
- `割る源石の数` は `理性剤使用数` の後にのみ判定されます。MAA は理性剤がない場合にのみ源石で理性を補充するため、`割る源石の数` にチェックを入れると `理性剤使用数` は 999 に固定され、理性剤を使い切ってからでないと源石を割らないようにします。

### ステージ

- ステージに目的の候補がない場合は、MAA で `現在/前回` を選び、ゲーム内で手動で目的ステージへ移動してください。
  画面は、右上にステージ名と残り理性、右下に自動指揮と作戦開始が表示されるステージ詳細に留めてください。
- この画面にいない場合、`現在/前回` は端末ホーム右下の「前回作戦」のステージへ自動で入ります。
- `作戦` → `高度な設定` で `ステージ名を入力する` を有効にし、手動でステージ番号を入力することもできます。現在ナビ可能なステージは以下の通りです：
  - すべてのメインステージ。末尾に `-NORMAL` または `-HARD` を付けて難易度を切り替え可能（10〜14章は標準/厄難、15章以降は通常/険地）。
  - 龍門幣・作戦記録の 5 / 6 ステージ。ただし `CE-6` / `LS-6` を入力してください。6 が連戦不可の場合、自動で 5 に切り替えます。
  - アーツ学・購買資格証・炭素材の第 5 ステージ。`CA-5` / `AP-5` / `SK-5` を入力してください。
  - すべてのSoCステージ。`PR-A-1` のように完全な番号を入力してください。
  - 殲滅作戦は以下の入力値に対応し、対応する Value を使用してください：
    - 当期殲滅作戦：Annihilation
    - チェルノボーグ：Chernobog@Annihilation
    - 龍門郊外：LungmenOutskirts@Annihilation
    - 龍門市街：LungmenDowntown@Annihilation

  - サイドストーリー内の `OF-1` / `OF-F3`。
  - 当期 SS イベントの後半 3 ステージ。自動で [API](https://api.maa.plus/MaaAssistantArknights/api/gui/StageActivityV2.json) から更新を取得後、画面下部に表示されます。
  - 復刻 SS イベント。`SSReopen-<ステージ接頭辞>` を入力すると、XX-1 ～ XX-9 を一括周回します（例：`SSReopen-IC`）。

### 殲滅作戦

- MAA は端末ホーム右上の殲滅ボタンからのみ遷移します。選択した殲滅ステージが `完全委任` を解放済みで、`PRTS 殲滅代理カード` を十分に所持していることを確認してください。
- 「400体撃破」を達成済みのステージのみ自動殲滅の使用を推奨します。
- ナビ中に殲滅入口が見つからない場合、今週の殲滅は完了済みとみなし、タスクは直接終了します（失敗扱いではありません）。
- ナビ中に `完全委任`（掃討）が利用可能かを確認します。利用不可の場合、タスクは失敗して終了します。
- 実行中は掃討券が十分かを**継続的には確認しません**。途中で掃討券が不足すると、以降は通常の自動指揮に戻り、所要時間が大幅に長くなる可能性があります。
- 清算時に今週の合成玉進捗（例：`1800 / 1800`）を認識し、上限到達後に自動停止します。
- 殲滅は常設ステージです。ステージ選択 / 代替ステージで選ばれた場合、その後の代替ステージは続けて認識・実行されません。
- 殲滅のドロップはペンギン急便および一図流へアップロードされません。
- 先に殲滅を回したい場合は、殲滅のみを指定した作戦タスクを別に追加し、既存の作戦タスクより上へドラッグしてください。高度な設定で週次スケジュールを有効にし、月曜日だけにチェックを入れると、月曜日のみ実行されます。

## 高度な設定

### 代替ステージ

代替ステージは当日の開放状況に応じて戦闘ステージを決定し、最初に開放されているステージを選びます。
これはスケジュールに近い機能であり、「ステージ選択に失敗したときの予備候補」にはなりません。

例：代替選択肢が `龍門幣-6(CE-6)`、 `1-7` 、`作戦記録-6(LS-6)` の場合：

- 当日に `龍門幣-6(CE-6)` が開放されていれば `龍門幣-6(CE-6)` に向かい、`1-7` と `作戦記録-6(LS-6)` には向かいません。この時点で `龍門幣-6(CE-6)` の自動指揮を解放していなければ、作戦タスクはエラーになります。
- 当日に `龍門幣-6(CE-6)` が開放されていなければ `1-7` に向かい、`龍門幣-6(CE-6)` には向かいません。この時点で `1-7` の自動指揮を解放していなければ、作戦タスクはエラーになります。
- `作戦記録-6(LS-6)` より前に常設の `1-7` が存在するため、この構成では MAA は `作戦記録-6(LS-6)` には決して向かいません。
- 同様に、代替候補で `殲滅` などの常設ステージが選ばれた場合、その後のステージも続けて認識されません。

### 週次スケジュール

- `タスク設定` - `作戦` - `高度な設定` で有効にします。この機能は UI 側で実装されています。
- 有効化後、日曜～土曜のうち、どの**ゲーム内曜日**にこの作戦タスクを実行するかをチェックできます。
- 曜日はゲーム内時間（各サーバーのタイムゾーン + 毎日 4:00 リセット）で計算され、端末のカレンダー日ではありません。例：CN サーバーでは現地 3:59 は前日扱いです。
- タスク開始時：週次スケジュールが有効で当日が未チェックの場合、この作戦タスクは**スキップ**されます（ログにタスクスキップと表示、失敗扱いではない）。後続タスクは続行します。
- 週次スケジュールを有効にしていない場合は、毎日実行を試みます。
- 週次スケジュールを有効にすると、「リストに当日開放されないステージを隠す」はオフになり、無効化されます。
- 典型的な使い方：殲滅のみの作戦タスクを別に追加し、週次スケジュールで月曜日だけにチェックを入れると、月曜日のみ実行されます。詳細は上の [殲滅作戦](#殲滅作戦) を参照。

### 連戦回数

MAA はユーザーが設定した連戦回数に基づいて戦闘を行います：

- **AUTOモード**（0）：
  - 連戦回数を自動選択：残り周回数（ステージ対応の最大回数まで）に基づいて調整。理性回復薬使用時は溢れを防ぐため使用量を自動で減らし、源石は設定回数に従い1個ずつ使用します
  - その倍率の1周分の理性が不足する場合、設定に従って理性を回復（先に回復薬、次に源石）して補填します。設定がない、または尽きている場合は任務を終了します。

- **数値モード**（中国版 1～10、海外版 1～6）：
  - 設定した回数で連戦を実行
  - 設定倍率の1周分の理性が不足する場合（例：5 回分しかないのに 6 倍を設定）、設定に従って理性を回復（先に回復薬、次に源石）して補填します。設定がない、または尽きている場合は任務を終了します。

- **切り替えない**（-1）：
  - ゲーム内の連戦回数設定を変更しません
  - 現在のゲーム内倍率の1周分の理性が不足する場合、設定に従って理性を回復（先に回復薬、次に源石）して補填します。設定がない、または尽きている場合は任務を終了します。

### 周回数指定

MAA は最大で指定回数まで戦闘を実行します。実際の戦闘回数は連戦回数で切り捨て整合されます：`floor(周回数指定 / 連戦回数) × 連戦回数`。指定回数を埋めるために 1 連戦未満の端数を切り出すことはありません（AUTO を除く、下記参照）。

例：現在の理性が 100、ステージ消費が 6、ステージ最大連戦が 10 の場合

- 周回数指定を 12、連戦回数を 5 に設定：`2（作戦開始） × 5 連戦 = 10 回`（`floor(12 / 5) × 5 = 10`）、消費理性は `10 × 6 = 60`。さらに 5 連戦すると 15 回になり上限 12 を超えるため、10 回で終了。
- 周回数指定を 12、連戦回数を AUTO に設定：まず「残り回数」と「現在の最大利用可能連戦」の小さい方を取り、10 連戦で 10 回；残り 2 回は 2 連戦で消化し、合計 12 回、消費理性は `12 × 6 = 72`。

### スクショ認識

- 素材ドロップの自動認識と統計に対応。あわせて [ペンギン急便データ統計処理部門](https://penguin-stats.io/) と [ワンシート攻略](https://ark.yituliu.cn/) にアップロードします（**ご注意：「ワンシート攻略」は実質的に簡体字中国語のみのため、翻訳ツールと併用してください**）。
- Penguin-Stats のレポート ID をカスタマイズ可能（`設定` → `実行設定`）。

## 異常検知

- `自動指揮` に自動でチェックを入れます。
- レベルアップ後もタスクを継続します。
- 自動指揮が失敗した場合はその回の行動を放棄し、再戦します。
