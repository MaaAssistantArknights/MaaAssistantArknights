# ウェイクアップ

エミュレータを自動起動し、クライアントを自動起動して、自動的にゲームへ入ります。

エミュレータの自動起動には追加設定が必要です。詳しくは起動設定をご覧のうえ、接続設定内の `ADB接続が失敗した場合、エミュレータの起動を試みる` にチェックを入れてください。

ゲームに接続切断のポップアップが表示されている場合、ウェイクアップは確認をタップして再接続し、そのままゲームに入ります。

## 起動時の認識タイムアウト

`ウェイクアップ` の通常設定で、起動時の認識タイムアウトを秒単位で設定できます。既定値は `120` 秒で、`10` から `600` までの整数を指定できます。エミュレータのコールドスタート時に黒い画面が長く続く場合は、この値を大きくしてください。

この設定は、起動時およびアカウント切替時の画面遷移において、各認識ステップで画面を認識できない状態が連続する時間を、実際の経過時間で制限します。認識に成功すると直ちに次へ進み、次のステップで計測をやり直します。指定した秒数だけ必ず待つ設定ではありません。認識済みの読み込み画面や更新画面は連続した認識失敗には含まれないため、起動処理全体の制限時間ではありません。

タイムアウト後は、従来どおりエラー処理またはゲームの再起動を試みます。この設定はウェイクアップのみに適用され、公開求人や基地など、ほかのタスクの待機時間には影響しません。

## アカウント切替

この機能は `構成を切り替える` または `スケジュール実行設定` と併用してください。`ウェイクアップ` タスクを実行するたびに、1回アカウント切替を行います。

切り替えはログイン済みのアカウントにのみ対応します。検索にはログイン名を使用します。入力した内容が、ログイン済みのすべてのアカウントの中で一意になるようにしてください。

- 例：
  - 公式サーバー：`123****8901` の場合、`123****8901`、`123`、`8901`、`3****8` のいずれでも可
  - Bilibiliサーバー：`张三` の場合、`张三`、`张`、`三` のいずれでも可
  - 繁体字中国語サーバー：Eメール形式（例：`ab****01@gmail.com`）。アスタリスクを含まない明文部分（例：`01@gmail`）の入力を推奨
  - YostarKRサーバー：Eメール形式（例：`ab****01@gmail.com`）。アスタリスクを含まない明文部分（例：`01@gmail`）の入力を推奨
