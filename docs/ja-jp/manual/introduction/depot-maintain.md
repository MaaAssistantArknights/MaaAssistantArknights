# 在庫維持

::: info UI 専用機能
本ページの機能は UI 層で実装されています。詳細は[始めに](../newbie.md#このドキュメントについて)を参照してください。
:::

在庫維持は、**材料を目標在庫数まで自動で周回する**タスクです。[倉庫アイテム認識](./tools.md#倉庫アイテム認識) でキャッシュされた在庫データに基づいて不足分を計算し、指定ステージを周回して目標数に到達したら停止します。

## 仕組み

1. タスク開始時（「タスク開始前に在庫データを更新」にチェックがある場合）、まず倉庫認識を実行して最新の在庫を取得します。
2. 各計画の目標在庫から現在の所持数を引いて、周回すべき不足分を計算します。
3. 不足がある材料について、対応する理智作戦タスクを自動的に追加します。
4. 各ステージのドロップ後に在庫キャッシュをリアルタイムで更新します。前の計画で入手した材料が後の計画の不足計算に影響します。
5. 各計画の開始直前に実行要否を判定します：目標在庫に既に達している場合、または理性がステージ消費未満かつ薬剤/源石の手段がない場合、その計画はスキップされます（ターミナルを開かず、遷移もせず）、理由はログに出力されます。

::: tip 在庫データの同期
在庫データはキャッシュ値であり、手動周回や素材の合成・消費後に実際とずれる場合があります。[データ更新](./user-data-update.md) タスクまたは [倉庫アイテム認識](./tools.md#倉庫アイテム認識) ツールで同期できます。
:::

## 計画設定

各計画には以下の内容が含まれます：

| 設定項目         | 説明                                                                                                                   |
| :--------------- | :--------------------------------------------------------------------------------------------------------------------- |
| ステージ選択     | 周回するステージを選択。通常ステージ、チップステージ、資源ステージ等に対応。「現在/前回」は非対応。                    |
| ドロップ素材指定 | 目標ドロップ素材を選択。各ステージには複数のドロップ素材がある場合があります。実際に周回したい素材を選択してください。 |
| 目標在庫         | 該当素材の目標所持数を設定。到達後、この計画は自動的に完了します。                                                     |
| 理性剤使用       | チェックすると理性剤の使用数を設定できます。                                                                           |
| 源石使用         | チェックすると源石の使用数を設定できます。                                                                             |

計画リストの項目は**ドラッグで順序を変更**できます。実行時に順番通りに処理されます。

::: tip 理性不足時のスキップ規則
- 理性剤または源石の予算を設定した計画は、理性不足でスキップされることはありません。理性が足りなくても出撃し、予算の範囲で理性を回復して戦闘を続けます。
- 予算未設定の計画は、目標在庫に既に達している場合、または理性がステージ消費未満かつ使える臨期薬がない場合に、出撃せず直接スキップされます。
- 判定は常に最新の状態で行われます：途中の計画が薬で理性を回復して目標在庫に達した後も、残った理性は後続の計画に使われます。
:::

### プリセット

以下のプリセットが組み込まれており、ワンクリックで計画を入力できます：

- **低級チップ（全職業）**：PR-A/B/C/D-1、目標各 20 個
- **上級チップセット（全職業）**：PR-A/B/C/D-2、目標各 20 個
- **龍門幣**：CE-6、目標 200 万
- **購買証明（赤チケット）**：AP-5、目標 5000
- **アーツ学全書・3**：CA-5、目標 200

## 詳細設定

### タスク開始前に在庫データを更新

チェックすると、タスク開始時に倉庫認識を実行して最新在庫を取得します。チェックを外すと前回キャッシュされた在庫データを使用します。

精度を重視する場合はチェックを推奨します。キャッシュが正確な場合や認識時間を節約したい場合はチェックを外してください。

### AUTO 代理倍率

チェックなしの場合は単倍（1×）代理で周回します。チェックした場合は現在の理智で周回可能な最大倍率で代理し、1 回の周回で目標在庫を超える場合があります。

### 「理性剤使用」/「源石使用」チェックボックスの有効化

各計画で対応する理性剤/源石行を表示するかを制御します。無効にすると全計画で理性剤や源石が一律に使用されません。

### 48 時間以内に期限切れの理性剤を使用

チェックすると、全計画で 48 時間以内に期限切れとなる理性剤（固定 2 日閾値）を優先的に使用します。理性剤の予算未設定の計画も臨期薬の使用を試みます。これらの計画が理性不足でスキップされるのは、このキューの実行中に既に戦闘が理性不足で終了し（このウィンドウ内の臨期薬を使い切った）後のみです。

### イベント期間中はスキップ

チェックすると、イベント開催中と検出された場合、在庫維持タスク全体をスキップします。

### 資源収集限時全天開放期間中はスキップ

チェックすると、資源収集ステージが限時全天開放期間中と検出された場合、在庫維持タスク全体をスキップします。
