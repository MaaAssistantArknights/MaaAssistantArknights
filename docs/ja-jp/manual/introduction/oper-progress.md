# オペレーター育成

オペレーター育成タスクは、計画リストの順に、指定したオペレーターを設定した**昇進**、**スキルランク**、**スキル特化**の目標まで自動で育成します。素材が足りない場合は加工所での合成、製造所での生産、購買資格証交換所での購入まで自動で行うため、ゲームを手動で操作する必要はありません。

## 機能説明

1 つの計画が 1 名のオペレーターに対応し、3 種類の目標は同時に設定でき、互いに競合しません。

- **昇進**：段階ごとに昇進し、各昇進の前にまず現在の段階の最大レベルまでレベルアップします。
- **素材の自動補完**：不足している素材は加工所で自動合成します。★5・★6 オペレーターの昇進2 に必要な上級SoCは製造所で生産し、SoC強化剤が足りない場合は購買資格証交換所で購入します。レシピが未解放、またはどうしても素材を補えない場合、その目標は失敗として記録され、タスクはこの計画の残りの目標と後続の計画を続行します。
- **スキル特化**：特化は一定時間訓練室を占有します。1 回の実行で特化トレーニングを開始できるのは最大 1 名分で、開始した後は同じ実行内の残りのオペレーターの特化目標はすべてスキップされます（訓練室が他のオペレーターに使用中の場合はその項目がスキップとして記録されます）。そのため計画した特化レベルに到達するには、通常タスクを複数回実行する必要があります。
- タスクの実行中は育成結果が 1 件ずつ出力され、終了時に成功・失敗・スキップの集計が出力されます。目標を達成した項目は計画リストから自動的に削除されます。
- タスクの実行中は計画リストを編集できません。

計画リストの項目は**ドラッグで順序を変更**でき、実行時はその順に 1 件ずつ育成します。

## 計画のインポート

UI で 1 名ずつ追加して目標を手動設定する以外に、JSON 計画を直接インポートできます。

1. 計画の JSON をクリップボードにコピーします。設定内の「アークナイツツールボックスでオンライン編集」リンクから、[アークナイツツールボックス](https://arkntools.app/#/material) でオンライン編集してエクスポートすることもできます。
2. オペレーター育成の設定で「クリップボードから読み取り」をクリックすると、解析された計画が現在のリストの末尾に追加されます。

計画の各配列要素が 1 名のオペレーターに対応します：

| フィールド      | 型     | 必須   | 説明                                                                                                                                           |
| :-------------- | :----- | :----- | :--------------------------------------------------------------------------------------------------------------------------------------------- |
| `role`          | string | いいえ | オペレーターの職業。値は下記の一覧を参照。省略時は `name` から自動判定され、同名で複数の職業がある場合は明示的に指定する必要があります         |
| `name`          | string | はい   | オペレーター名（例：`アーミヤ` / `Amiya`）。空にはできません                                                                                   |
| `elite`         | int    | いいえ | 昇進の目標段階。`1` または `2`。省略 / `0` は未設定を表します                                                                                  |
| `skill_level`   | int    | いいえ | スキルランクの目標。`2` ~ `7`。省略 / `0` は未設定を表します                                                                                   |
| `skill_mastery` | int[]  | いいえ | スキル 1 / 2 / 3 の特化目標レベルを順に指定。各値は `0` ~ `3`。低レアのオペレーターでは int[1]、int[2] のような長さ 3 未満の配列も指定できます |

`role` の値はアンパックデータの `profession` と一致します：`Pioneer`（先鋒）、`Warrior`（前衛）、`Tank`（重装）、`Sniper`（狙撃）、`Caster`（術師）、`Medic`（医療）、`Support`（補助）、`Special`（特殊）。
`level` フィールドは予約済みで、まだ対応していません。

例：

```json
[{"role": "Warrior","name":"チェン","elite":2,"skill_level": 7, "skill_mastery":[0,0,3]}]
```

上の例は、前衛「チェン」を昇進2・スキルランク7 まで育成し、スキル3 を特化3 まで上げることを表します。

::: tip
フィールド名は大文字と小文字を区別し、上表以外のフィールドは受け付けません。いずれかの計画を解析できない場合、このインポートは全体が無効となり、原因がログに出力されます。

インポートでは前提条件は自動で補完されません。たとえば `skill_level` を設定せず `skill_mastery` だけを設定した場合、オペレーターの現在のスキルランクが 7 未満だと、実行時に前提条件を満たさずその特化目標は失敗します。`skill_level: 7` も併せて設定してください。
:::
