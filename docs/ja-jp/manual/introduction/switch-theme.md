# テーマ変更

ゲームのメイン画面 UI テーマを切り替えます。

## 使い方

1. ｢テーマ変更｣ タスクをタスクキューに追加します。
2. タスク設定に候補テーマ名を入力します。ゲーム内のテーマ一覧に表示される名称（中国サーバーでは ｢日间｣（昼）｢夜间｣（夜）など）です。
3. 複数入力した場合は実行ごとにランダムに 1 つ選択され、1 つのみの場合は常にそれに切り替わります。
4. 何も入力していない場合、タスクはスキップされログに表示されます。

タスクはまずメイン画面に戻ってからテーマ一覧を検索します。現在のページを確認し、見つからなければリストの先頭まで一気にスクロールし、下方向へ順に探します。テーマ名は文字認識で照合されるため、使用頻度の低い漢字が形の類似した字に誤認識されて見つからない場合があります（例: 凇 が 淞 と誤認識されるケース。実テストで確認された誤認識は内蔵の補正で対応済み）。それでも見つからない場合は ｢問題報告｣ からログの圧縮ファイルを提出してください。ログには実際の認識結果が含まれ、補正の追加に役立ちます。

::: tip フォールバックで切り替わったテーマを元に戻す
MAA 未対応の新テーマに切り替えると、後続タスクがそのメイン画面を認識できず、昼テーマへ戻すフォールバックが作動することがあります。本タスクをタスクキューの最後に置き、元のテーマ名を入力しておけば、すべてのタスク終了後にテーマを元に戻せます。
:::
