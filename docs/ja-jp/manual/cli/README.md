Rust で書かれたシンプルな MAA コマンドラインツールです。

## 機能

- `maa fight` や `maa run <task>` など、定義済みまたはカスタムタスクを実行します。
- `maa install` と `maa update` で MaaCore とリソースをインストール・更新します。
- `maa self update` で自身を更新します。
