# 始めに

::: info このドキュメントについて
本マニュアルは主に **Windows 版 MAA（WPF デスクトップ版）** を対象に説明します。MAA Team が主に保守しているのは Windows 向け WPF UI です。maa-cli と macOS 版は少数の開発者が保守しており、機能差や遅れがある場合があります。

一部の機能（在庫維持、定時実行、圧縮パッケージのドラッグ更新など）は UI 層で実装されており、コア（MaaCore）には含まれません。maa-cli、macOS 版、または MaaCore を直接呼び出すサードパーティ UI では、これらの機能が使えない場合があり、各自で実装する必要があります。UI 専用機能を扱うページの先頭には注記があります。
:::

## 準備

::::steps

1. システムバージョンの確認

   MAA は Windows 10 / 11 のみサポートしています。それ以前のバージョンの Windows については[よくある質問](./faq.md#システムの問題)を確認してください。

   Windows 以外のユーザーは[エミュレーターおよびデバイスのサポート](./device/)をご覧ください。

2. エミュレータのサポートを確認

   [エミュレーターおよびデバイスのサポート](./device/)を確認し、使用しているエミュレータのサポート状況を確認してください。

3. ダウンロードとインストール

   [ダウンロードとインストール](./install.md)をご覧ください。

4. エミュレータの解像度を正しく設定する

   エミュレーターの解像度は横画面の `1280x720` または `1920x1080` にするべきです；YosterEN のプレイヤーには、`1920x1080` が必須です。

::::

## 初期設定

0. 自動検出を使用する場合は、**1 つ**のエミュレータのみを実行し、他の Android デバイスがコンピュータに接続されていないことを確認してください。

1. 設定ガイドに従って設定を行ってください。MAA は実行中のエミュレータを自動的に検出します。検出に失敗した場合や、複数起動が必要な場合は[接続設定](./connection.md)を参照してください。

2. MAA は起動時にゲームリソースの更新を自動的に確認・適用します。更新はシステムがアイドル状態のときに自動的に読み込まれ、再起動なしで反映されます。

3. 左側のタスクリストをドラッグしてタスクの順序を並べ替え、チェックボックスのオン/オフで実行するタスクを選択してください。タスク右側の歯車アイコンをクリックすると、そのタスクの詳細設定を展開できます。

4. Link Start!

1. `設定` - `問題報告` - `サポート用ZIPを生成` で、共有しやすいログ圧縮パッケージを生成できます。ログは非常に重要です。他の人に助けを求める際は、必ずログ圧縮パッケージを一緒に持って行ってください。
   MAA が完全に起動できず設定パネルに入れない場合は、手動で MAA インストールディレクトリ（`MAA.exe` があるフォルダ）に移動し、`debug`、`config`、`cache` の 3 つのフォルダを圧縮して提供してください。
   フィードバック先：[GitHub Issues](https://github.com/MaaAssistantArknights/MaaAssistantArknights/issues)（`設定` - `問題報告` - `フィードバック` からもアクセスできます）。

2. MAA では、ユーザーの皆様の多様なニーズに可能な限りお応えするため、数多くのカスタマイズオプションを用意しています。機能が足りないと思った場合は、見つかっていないだけの可能性があります。例えば、「ステージ名の手入力」や「配置済みオペレーターを寮に入れない」などです。

3. 一部のチェックボックスは、右クリックで半選択状態に切り替えることができます。この状態のチェックボックスは、MAA の次回起動時に自動的にクリアされます。`1 回のみ` と理解できます。
