# 로그인

자동으로 에뮬레이터를 시작하고, 클라이언트를 자동으로 시작하며, 게임에 자동으로 로그인합니다.

자동으로 에뮬레이터를 시작하려면 별도의 설정이 필요합니다. 자세한 내용은 `설정` - `시작 설정`을 참조하세요.

게임에 연결 끊김 팝업이 표시되어 있으면, 로그인 작업이 확인을 눌러 다시 연결한 뒤 게임에 계속 진입합니다.

## 시작 화면 인식 제한 시간

`로그인` 작업의 일반 설정에서 시작 화면 인식 제한 시간을 초 단위로 지정할 수 있습니다. 기본값은 `120`초이며, `10`부터 `600`까지의 정수를 입력할 수 있습니다. 에뮬레이터를 처음 실행할 때 검은 화면이 오래 지속되면 이 값을 늘려 주세요.

이 설정은 시작 및 계정 전환 과정의 각 화면 인식 단계에서 화면을 연속으로 인식하지 못하는 시간을 실제 경과 시간으로 제한합니다. 인식에 성공하면 즉시 다음 단계로 진행하며, 다음 단계에서 시간을 새로 계산합니다. 입력한 시간만큼 무조건 기다리는 설정은 아닙니다. 인식된 로딩 또는 업데이트 화면은 연속 인식 실패에 해당하지 않으므로, 전체 시작 과정의 제한 시간도 아닙니다.

제한 시간이 지나면 기존의 오류 처리 또는 게임 재시작 처리가 적용됩니다. 이 설정은 로그인 작업에만 적용되며, 공개모집이나 기반시설 등 다른 작업의 대기 시간에는 영향을 주지 않습니다.

## 계정 전환

이 기능은 설정 전환 또는 정기 실행과 함께 사용해야 하며, `로그인` 작업이 실행될 때마다 계정 전환 작업이 수행됩니다.

이미 로그인된 계정으로만 전환할 수 있습니다. 로그인 이름으로 검색되므로 입력 내용이 모든 로그인된 계정에서 고유하도록 해주세요.

- 예시:
  - 공식 서버: `123****8901`은 `123****8901`, `123`, `8901`, `3****8`로 입력될 수 있습니다.
  - Bilibili 서버: `张三`은 `张三`, `张`, `三`로 입력될 수 있습니다.
  - 번체 중국어 서버: 계정은 Email 형식이며(예: `ab****01@gmail.com`), 별표가 없는 평문 부분(예: `01@gmail`) 입력을 권장합니다.
  - YostarKR 서버: 계정은 Email 형식이며(예: `ab****01@gmail.com`), 별표가 없는 평문 부분(예: `01@gmail`) 입력을 권장합니다.
