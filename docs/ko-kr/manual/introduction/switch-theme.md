# 테마 변경

게임 메인 화면의 UI 테마를 전환합니다.

## 사용 방법

1. ｢테마 변경｣ 작업을 작업 대기열에 추가합니다.
2. 작업 설정에 후보 테마 이름을 입력합니다. 게임 내 테마 목록에 표시되는 이름입니다(중국 서버 기준 ｢日间｣(주간), ｢夜间｣(야간) 등).
3. 여러 개를 입력하면 실행할 때마다 무작위로 하나가 선택되고, 하나만 입력하면 항상 해당 테마로 전환됩니다.
4. 아무 이름도 입력하지 않으면 작업을 건너뛰고 로그에 표시됩니다.

작업은 먼저 메인 화면으로 돌아간 뒤 테마 목록에서 대상을 찾습니다. 현재 페이지를 확인하고, 찾지 못하면 목록 맨 위까지 빠르게 스크롤한 뒤 아래 방향으로 화면 단위로 탐색합니다. 테마 이름은 문자 인식으로 매칭되므로 일부 글자가 모양이 비슷한 다른 글자로 잘못 인식되어 찾지 못할 수 있습니다(예: 凇을 淞으로 잘못 인식 — 테스트에서 확인된 오인식은 내장 보정으로 처리됨). 그래도 찾지 못하는 경우 ｢문제 보고｣로 로그 압축 파일을 제출해 주세요. 로그에 실제 인식 결과가 포함되어 있어 보정 추가에 도움이 됩니다.

::: tip 폴백으로 전환된 테마 복원
MAA가 아직 지원하지 않는 새 테마로 전환하면 이후 작업이 해당 메인 화면을 인식하지 못해 주간 테마로 되돌리는 폴백이 작동할 수 있습니다. 이 작업을 작업 대기열 맨 끝에 배치하고 해당 테마 이름을 입력해 두면 모든 작업이 끝난 후 테마를 되돌릴 수 있습니다.
:::
