# 오퍼레이터 육성

오퍼레이터 육성 작업은 계획 목록의 순서대로 지정한 오퍼레이터를 설정한 **정예화**, **스킬 레벨**, **스킬 전문화** 목표까지 자동으로 육성합니다. 재료가 부족하면 가공소에서 합성하고, 제조소에서 생산하거나 구매 증명서 교환소에서 구매하는 것까지 자동으로 처리하므로 게임을 직접 조작할 필요가 없습니다.

## 기능 설명

계획 하나가 오퍼레이터 한 명에 대응하며, 세 가지 목표를 동시에 설정할 수 있고 서로 충돌하지 않습니다.

- **정예화**: 단계별로 승급하며, 승급 전에 먼저 현재 단계의 최대 레벨까지 레벨업합니다.
- **재료 자동 보충**: 부족한 재료는 가공소에서 자동으로 합성합니다. 5성·6성 오퍼레이터의 정예화 2에 필요한 듀얼 칩은 제조소에서 생산하고, 칩 첨가제가 부족하면 구매 증명서 교환소에서 구매합니다. 레시피가 아직 해금되지 않았거나 재료를 끝내 채울 수 없으면 해당 목표는 실패로 기록되고, 작업은 이 계획의 나머지 목표와 이후 계획을 계속 처리합니다.
- **스킬 전문화**: 전문화는 훈련실을 일정 시간 점유합니다. 한 번 실행할 때 전문화 훈련을 시작할 수 있는 것은 최대 한 명이며, 훈련을 시작한 뒤에는 같은 실행에서 나머지 오퍼레이터의 전문화 목표는 모두 건너뜁니다(훈련실을 다른 오퍼레이터가 사용 중이면 해당 항목은 건너뜀으로 기록됩니다). 따라서 계획한 전문화 레벨에 도달하려면 보통 작업을 여러 번 실행해야 합니다.
- 작업이 진행되는 동안 육성 결과가 항목별로 출력되고, 종료할 때 성공·실패·건너뜀 요약이 출력됩니다. 목표를 달성한 항목은 계획 목록에서 자동으로 제거됩니다.
- 작업 실행 중에는 계획 목록을 편집할 수 없습니다.

계획 목록의 항목은 **드래그로 순서를 바꿀** 수 있으며, 실행할 때는 그 순서대로 하나씩 육성합니다.

## 계획 가져오기

UI에서 오퍼레이터를 하나씩 추가해 목표를 직접 설정하는 것 외에, JSON 계획을 바로 가져올 수 있습니다.

1. 계획 JSON을 클립보드에 복사합니다. 설정의 '명일방주 공구 상자에서 온라인 편집' 링크를 눌러 [명일방주 공구 상자](https://arkntools.app/#/material)에서 온라인으로 편집한 뒤 내보낼 수도 있습니다.
2. 오퍼레이터 육성 설정에서 '클립보드에서 읽기'를 클릭하면 분석된 계획이 현재 목록 끝에 추가됩니다.

계획의 각 배열 항목이 오퍼레이터 한 명에 대응합니다:

| 필드            | 형식   | 필수   | 설명                                                                                                                                                   |
| :-------------- | :----- | :----- | :----------------------------------------------------------------------------------------------------------------------------------------------------- |
| `role`          | string | 아니요 | 오퍼레이터의 직업. 값은 아래 목록을 참고하세요. 생략하면 `name`으로 자동 판별하며, 같은 이름에 여러 직업이 있으면 명시해야 합니다                      |
| `name`          | string | 예     | 오퍼레이터 이름(예: `아미야` / `Amiya`). 비워 둘 수 없습니다                                                                                           |
| `elite`         | int    | 아니요 | 정예화 목표 단계. `1` 또는 `2`. 생략 / `0`은 미설정을 뜻합니다                                                                                         |
| `skill_level`   | int    | 아니요 | 스킬 레벨 목표. `2` ~ `7`. 생략 / `0`은 미설정을 뜻합니다                                                                                              |
| `skill_mastery` | int[]  | 아니요 | 스킬 1 / 2 / 3의 전문화 목표 레벨을 순서대로 지정. 각 값은 `0` ~ `3`. 저성급 오퍼레이터는 int[1], int[2]처럼 길이가 3 미만인 배열도 지정할 수 있습니다 |

`role`의 값은 언팩 데이터의 `profession`과 같습니다: `Pioneer`(뱅가드), `Warrior`(가드), `Tank`(디펜더), `Sniper`(스나이퍼), `Caster`(캐스터), `Medic`(메딕), `Support`(서포터), `Special`(스페셜리스트).
`level` 필드는 예약되어 있으며 아직 지원하지 않습니다.

예:

```json
[{"role": "Warrior","name":"첸","elite":2,"skill_level": 7, "skill_mastery":[0,0,3]}]
```

위 예는 가드 '첸'을 정예화 2, 스킬 레벨 7까지 육성하고 스킬 3을 전문화 3까지 올린다는 뜻입니다.

::: tip
필드 이름은 대소문자를 구분하며, 위 표에 없는 필드는 허용되지 않습니다. 계획 중 하나라도 분석할 수 없으면 이번 가져오기 전체가 적용되지 않고, 로그에 원인이 출력됩니다.

가져오기는 선행 조건을 자동으로 채우지 않습니다. 예를 들어 `skill_level`을 설정하지 않고 `skill_mastery`만 설정한 경우, 오퍼레이터의 현재 스킬 레벨이 7 미만이면 실행할 때 선행 조건을 충족하지 못해 해당 전문화 목표가 실패합니다. `skill_level: 7`도 함께 설정하세요.
:::
