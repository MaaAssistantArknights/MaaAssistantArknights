# 재고 유지

::: info UI 전용 기능
이 페이지의 기능은 UI 계층에서 구현됩니다. 자세한 내용은 [초보자 가이드](../newbie.md#이-문서에-대해)를 참고하세요.
:::

재고 유지는 **재료를 목표 재고량까지 자동으로 파밍하는** 작업입니다. [창고 인식](./tools.md#창고-인식)에서 캐시된 재고 데이터를 기반으로 부족분을 계산하고, 지정 스테이지를 파밍하여 목표량에 도달하면 중지합니다.

## 작동 방식

1. 작업 시작 시(「작업 시작 전 재고 데이터 업데이트」에 체크한 경우) 먼저 창고 인식을 수행하여 최신 재고를 가져옵니다.
2. 각 계획의 목표 재고에서 현재 보유 수량을 빼서 파밍해야 할 부족분을 계산합니다.
3. 부족한 재료에 대해 해당 이성 작전 작업을 자동으로 추가합니다.
4. 각 스테이지 드롭 후 재고 캐시를 실시간으로 업데이트합니다. 이전 계획에서 파밍한 재료가 이후 계획의 부족분 계산에 영향을 줍니다.

::: tip 재고 데이터 동기화
재고 데이터는 캐시 값이며, 수동 파밍, 합성, 재료 사용 후 실제와 다를 수 있습니다. [데이터 업데이트](./user-data-update.md) 작업이나 [창고 인식](./tools.md#창고-인식) 도구로 동기화할 수 있습니다.
:::

## 계획 설정

각 계획에는 다음 내용이 포함됩니다:

| 설정 항목        | 설명                                                                                                                        |
| :--------------- | :-------------------------------------------------------------------------------------------------------------------------- |
| 스테이지 선택    | 파밍할 스테이지를 선택합니다. 일반 스테이지, 칩 스테이지, 자원 스테이지 등을 지원합니다. 「현재/이전」은 지원하지 않습니다. |
| 드롭 재료 지정   | 목표 드롭 재료를 선택합니다. 각 스테이지에는 여러 드롭 재료가 있을 수 있으며, 실제로 파밍할 재료를 선택하세요.              |
| 목표 재고        | 해당 재료의 목표 보유 수량을 설정합니다. 달성 후 이 계획은 자동으로 완료됩니다.                                             |
| 이성 회복제 사용 | 체크하면 이성 회복제 사용 수량을 설정할 수 있습니다.                                                                        |
| 순오리지늄 사용  | 체크하면 순오리지늄 사용 수량을 설정할 수 있습니다.                                                                         |

계획 목록의 항목은 **드래그하여 순서를 변경**할 수 있습니다. 실행 시 순서대로 처리됩니다.

### 프리셋

다음 프리셋이 내장되어 있으며, 원클릭으로 계획을 채울 수 있습니다:

- **저급 칩(전 직업)**: PR-A/B/C/D-1, 목표 각 20개
- **고급 칩 세트(전 직업)**: PR-A/B/C/D-2, 목표 각 20개
- **용문폐**: CE-6, 목표 200만
- **구매 증명(빨간 티켓)**: AP-5, 목표 5000
- **스킬 개론·卷3**: CA-5, 목표 200

## 고급 설정

### 작업 시작 전 재고 데이터 업데이트

체크하면 작업 시작 시 창고 인식을 수행하여 최신 재고를 가져옵니다. 체크 해제 시 이전에 캐시된 재고 데이터를 사용합니다.

정확도를 중시한다면 체크를 권장합니다. 캐시가 정확하거나 인식 시간을 절약하려면 체크를 해제하세요.

### AUTO 대리 배율

체크 해제 시 단배(1×) 대리로 파밍합니다. 체크 시 현재 이성으로 파밍 가능한 최대 배율로 대리하며, 1회 파밍으로 목표 재고를 초과할 수 있습니다.

### 「이성 회복제 사용」/「순오리지늄 사용」 체크박스 활성화

각 계획에서 해당 회복제/오리지늄 행을 표시할지를 제어합니다. 비활성화하면 모든 계획에서 회복제나 오리지늄이 일괄적으로 사용되지 않습니다.

### 48시간 이내 만료되는 이성 회복제 사용

체크하면 모든 계획에서 48시간 이내 만료되는 이성 회복제(고정 2일 임계값)를 우선적으로 사용합니다.

### 이벤트 기간 중 건너뛰기

체크하면 이벤트 진행 중으로 감지된 경우, 재고 유지 작업 전체를 건너뜁니다.

### 자원 수집 한정 전일 개방 기간 중 건너뛰기

체크하면 자원 수집 스테이지가 한정 전일 개방 기간 중으로 감지된 경우, 재고 유지 작업 전체를 건너뜁니다.
