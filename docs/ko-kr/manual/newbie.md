# 초보자 가이드

한 문장으로 배우기!

::: info 이 문서에 대해
이 매뉴얼은 주로 **Windows 버전 MAA(WPF 데스크톱 클라이언트)** 를 기준으로 설명합니다. MAA Team이 주로 유지보수하는 것은 Windows용 WPF UI입니다. maa-cli와 macOS 버전은 소수의 개발자가 유지보수하며, 기능 차이 또는 지연이 있을 수 있습니다.

일부 기능(재고 유지, 정기 실행, 압축 패키지 드래그 업데이트 등)은 UI 계층에서 구현되며 코어(MaaCore)에는 포함되지 않습니다. maa-cli, macOS 버전, 또는 MaaCore를 직접 호출하는 서드파티 UI에서는 이러한 기능을 사용할 수 없을 수 있으며 직접 구현해야 합니다. UI 전용 기능을 다루는 문서 페이지 상단에는 표시가 있습니다.
:::

## 사전 준비

:::: steps

1. 시스템 버전 확인

   MAA 는 Windows 10/11만 지원합니다. 이전 버전의 Windows를 사용하는 경우 [FAQ](./faq.md#런타임-문제)를 참조하세요.

   Windows 사용자가 아닌 경우 [에뮬레이터 및 장치 지원](./device/)을 참조하세요.

2. 에뮬레이터 지원 확인

   [에뮬레이터 및 지원 장치](./device/)를 참조하여 사용 중인 에뮬레이터가 지원되는지 확인하세요.

3. 다운로드 및 설치

   [다운로드 및 설치](./install.md)를 참조하세요.

4. 에뮬레이터 해상도 설정

   에뮬레이터 해상도는 가로 모드에서 `1280x720` 또는 `1920x1080`이어야 합니다. YosterEN 플레이어의 경우 `1920x1080`이어야 합니다.

::::

## 초기 설정

0. 자동 감지를 사용하려면 **1개** 에뮬레이터만 실행하고, 다른 Android 기기가 컴퓨터에 연결되어 있지 않은지 확인하세요.

1. 설정 가이드에 따라 설정하세요. MAA가 실행 중인 에뮬레이터를 자동으로 감지합니다. 감지에 실패하거나 다중 실행이 필요한 경우 [연결 설정](./connection.md)을 참조하세요.

2. MAA는 시작 시 게임 리소스 업데이트를 자동으로 확인하고 적용합니다. 업데이트는 시스템이 유휴 상태일 때 자동으로 로드되며, 재시작 없이 적용됩니다.

3. 왼쪽의 작업 목록을 드래그하여 작업 순서를 정리하고, 체크박스를 선택하거나 해제하여 실행할 작업을 선택하세요. 작업 우측의 톱니바퀴 아이콘을 클릭하여 해당 작업의 상세 설정을 펼칠 수 있습니다.

4. Link Start!

1. `설정` - `문제 보고` - `로그 압축 파일 생성` 을 통해 공유하기 쉬운 로그 압축 패키지를 생성할 수 있습니다. 로그는 매우 중요합니다. 다른 사람에게 도움을 요청할 때는 반드시 로그 압축 패키지를 함께 제공하세요.
   MAA가 완전히 시작되지 않아 설정 패널에 들어갈 수 없는 경우, 수동으로 MAA 설치 디렉토리(`MAA.exe`가 있는 폴더)로 이동하여 `debug`, `config`, `cache` 세 폴더를 압축하여 함께 제공하세요.
   피드백 주소: [GitHub Issues](https://github.com/MaaAssistantArknights/MaaAssistantArknights/issues)(`설정` - `문제 보고` - `문제 제보/피드백` 를 통해서도 접근 가능).

2. MAA는 모든 사용자의 다양한 요구를 최대한 충족시키기 위해 많은 사용자 정의 옵션을 제공합니다. MAA에 특정 기능이 없는 것 같다면, 해당 기능을 찾지 못한 것일 가능성이 큽니다. 예를 들어, `스테이지 코드 수동 입력` 및 `이미 배치된 오퍼레이터 숙소 배치 X` 등의 기능이 있습니다.

3. 일부 체크박스의 경우, 오른쪽 클릭으로 반선택 상태로 변경할 수 있습니다. 이 상태의 체크박스는 MAA가 다음에 시작될 때 자동으로 해제됩니다. `1회만`으로 이해할 수 있습니다.
