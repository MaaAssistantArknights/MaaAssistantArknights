# 倉庫維持

::: info UI 專屬功能
本頁功能由 UI 層實作，詳見[新手上路](../newbie.md#關於本文檔)中的說明。
:::

倉庫維持是一個**自動化刷材料到目標庫存**的任務。它會根據 [倉庫辨識](./tools.md#倉庫辨識) 中快取的庫存資料，自動計算缺口並刷取指定關卡，直到材料數量達到目標值後停止。

## 工作原理

1. 任務開始時（如果勾選了「任務開始前更新庫存資料」），先執行一次倉庫辨識，取得最新的材料庫存。
2. 根據每條計畫中設定的目標庫存，減去目前已有數量，計算需要刷取的缺口。
3. 對有缺口的材料，自動新增對應的理智作戰任務。
4. 每次關卡掉落後，即時更新庫存快取，前序計畫刷出的材料會影響後續計畫的缺口計算。
5. 每條計畫開始前會即時判定是否需要執行：庫存已達標，或理智低於關卡消耗且無藥劑/源石手段時，直接跳過該計畫（不進終端、不導航），並在日誌中說明原因。

::: tip 庫存資料同步
庫存資料是快取值，手動刷關、合成或消耗材料後可能與實際不一致。可透過 [更新資料](./user-data-update.md) 任務或 [倉庫辨識](./tools.md#倉庫辨識) 工具同步。
:::

## 計畫設定

每條計畫包含以下內容：

| 設定項     | 說明                                                                     |
| :--------- | :----------------------------------------------------------------------- |
| 關卡選擇   | 選擇刷取的關卡。支援常規關卡、晶片本、資源關卡等，不支援「當前/上次」。  |
| 指定掉落物 | 選擇目標掉落材料。每個關卡可能有多個可掉落物，請選擇實際需要刷取的材料。 |
| 目標庫存   | 設定該材料的目標持有數量。達到後該條計畫自動完成。                       |
| 吃理智藥   | 勾選後可設定使用理智藥的數量。                                           |
| 吃源石     | 勾選後可設定碎源石的數量。                                               |

計畫清單中的項目可以**拖曳調整順序**。執行時會按順序逐條執行。

::: tip 理智不足時的跳過規則
- 設定了理智藥或源石預算的計畫不會被理智不足判定跳過：即使理智不夠，也會進圖並按預算回覆理智繼續作戰。
- 未設預算的計畫在庫存已達標、或理智低於關卡消耗且無臨期藥可用時，會被直接跳過，不進圖查看。
- 判定使用的是最新狀態：中間計畫吃藥打到目標庫存後，剩餘的理智仍會流向後續關卡。
:::

### 預設

內建以下預設，可一鍵填充計畫：

- **低級晶片（全職業）**：PR-A/B/C/D-1，目標各 20 個
- **高級晶片組（全職業）**：PR-A/B/C/D-2，目標各 20 個
- **龍門幣**：CE-6，目標 200 萬
- **採購憑證（紅票）**：AP-5，目標 5000
- **技巧概要·卷3**：CA-5，目標 200

## 進階設定

### 任務開始前更新庫存資料

勾選後，任務開始時會先執行一次倉庫辨識以取得最新庫存。取消勾選則使用上次快取的庫存資料。

建議保持勾選，除非你確定快取資料仍然準確，或想節省辨識時間。

### AUTO 代理倍率

未勾選時按單倍（1×）代理刷取；勾選後按目前理智可刷的最大倍率代理，單次刷取數量可能超過目標庫存上限。

### 啟用「吃理智藥」/「吃源石」勾選框

控制各計畫是否顯示對應的理智藥/源石行。關閉後所有計畫統一不使用理智藥或源石。

### 使用 48 小時內過期的理智藥

勾選後，所有計畫都會優先使用 48 小時內即將過期的理智藥（固定 2 天閾值）。未設理智藥預算的計畫也會嘗試使用臨期藥；只有當本輪任務佇列中已有戰鬥因理智不足結束（本視窗內的臨期藥已用完）後，這些計畫才會被理智不足判定跳過。

### 活動期間跳過

勾選後，當檢測到有活動進行中時，跳過整個倉庫維持任務。

### 資源收集限時全天開放期間跳過

勾選後，當檢測到資源收集關卡處於限時全天開放期間時，跳過整個倉庫維持任務。
