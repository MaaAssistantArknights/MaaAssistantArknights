# 倉庫維持

::: info UI 專屬功能
本頁功能由 UI 層實作，詳見[新手上路](../newbie.md)中的說明。
:::

倉庫維持是一個**自動化刷材料到目標庫存**的任務。它會根據 [倉庫辨識](./tools.md#倉庫辨識) 中快取的庫存資料，自動計算缺口並刷取指定關卡，直到材料數量達到目標值後停止。

## 工作原理

1. 任務開始時，會先用當時快取的庫存數據逐條計畫判定缺口，這一步稱為預檢。預檢中已充足的計畫會記入日誌並跳過，不會加入本輪刷取列表，之後也不再複查。預檢發生在倉庫辨識之前，用的是辨識前的快取數據。
2. 對預檢中有缺口的材料，自動新增對應的理智作戰任務；勾選了 ｢任務開始前更新庫存資料｣ 時，會在計畫執行前先執行一次倉庫辨識。
3. 每次關卡掉落後，即時更新庫存快取，前序計畫刷出的材料會影響後續計畫的缺口計算。
4. 每條計畫開始前會即時判定是否需要執行：庫存已達標，或按最近一場戰鬥回報的理智估算的目前理智低於本關卡單次進圖的最低消耗、且該計畫無藥劑/源石手段時，直接跳過該計畫（不進終端、不導航），並在日誌中說明原因。倉庫辨識更新的數據從這一步開始生效。若辨識後發現已跳過的計畫實際庫存不足，會記錄提示，重新執行任務即可按實際庫存刷取。臨期藥何時視為不可用，見 ｢[使用 48 小時內過期的理智藥](#使用-48-小時內過期的理智藥)｣ 。

::: tip 庫存資料同步
庫存資料是快取值，手動刷關、合成或消耗材料後可能與實際不一致。可透過 [更新資料](./user-data-update.md) 任務或 [倉庫辨識](./tools.md#倉庫辨識) 工具同步。
:::

## 計畫設定

每條計畫包含以下內容：

| 設定項     | 說明                                                                     |
| :--------- | :----------------------------------------------------------------------- |
| 關卡選擇   | 選擇刷取的關卡。支援常規關卡、晶片本、資源關卡等，不支援 ｢當前/上次｣ 。  |
| 指定掉落物 | 選擇目標掉落材料。每個關卡可能有多個可掉落物，請選擇實際需要刷取的材料。 |
| 目標庫存   | 設定該材料的目標持有數量。達到後該條計畫自動完成。                       |
| 吃理智藥   | 勾選後可設定使用理智藥的數量。                                           |
| 吃源石     | 勾選後可設定碎源石的數量。                                               |

計畫清單中的項目可以**拖曳調整順序**。執行時會按順序逐條執行；開啟 ｢[按庫存達成率排序執行](#按庫存達成率排序執行)｣ 後，執行時改按達成率排序執行，拖曳順序僅在未開啟該選項時生效。

::: tip 理智不足時的跳過規則

- 理智判定依據的是本次執行的任務鏈中最近一場進圖戰鬥（倉庫維持的計畫或獨立理智作戰）回報的理智值，並按每 6 分鐘回復 1 點、不足 6 分鐘按 6 分鐘計算來估算目前值（不超過理智上限）。
- 設定了理智藥或源石預算的計畫不會被理智不足判定跳過：即使理智不夠，也會進圖並按預算回覆理智繼續作戰。
- 未設預算的計畫在庫存已達標、或估算的目前理智低於本關卡單次進圖的最低消耗且臨期藥不可用（判定見 ｢使用 48 小時內過期的理智藥｣ ）時，會被直接跳過，不進圖查看。
- 判定使用的是最新狀態：中間計畫吃藥打到目標庫存後，剩餘的理智仍會流向後續關卡。

:::

### 預設

內建以下預設，可一鍵填充計畫：

- **低級晶片（全職業）**：PR-A/B/C/D-1，目標各 20 個（4 倍六星幹員養成消耗）
- **高級晶片組（全職業）**：PR-A/B/C/D-2，目標各 32 個（4 倍六星幹員養成消耗）
- **龍門幣**：CE-6，目標 500 萬（4 倍六星幹員養成消耗）
- **採購憑證（紅票）**：AP-5，目標 8000（8 個六星信物 + 8 個五星信物 + 每月模組塊）
- **技巧概要·卷3**：CA-5，目標 400 個（4 倍六星幹員養成消耗）

### 當前活動

當有 SideStory 活動進行中時，預設選單還會列出當前活動；復刻與新活動同時進行時會分別列出。點擊活動名，會把該活動關卡表中掉落為材料的關卡一對一生成計畫，目標庫存統一為 200，匯入後請按自己的兌換計劃調整目標數量。

若 ｢[活動期間跳過](#活動期間跳過)｣ 處於開啟狀態，匯入時會有提示：這些計畫在活動期間不會執行。

## 進階設定

### 任務開始前更新庫存資料

勾選後，計畫執行前會先執行一次倉庫辨識，把庫存快取糾正為實際值。取消勾選則不執行辨識，快取保持原有值，並仍會隨本輪關卡掉落即時累加。

每條計畫開始時都會用最新快取重新判定缺口，這與是否勾選無關。勾選帶來的差異只是多一次辨識糾正，尤其是向下修正手動消耗造成的快取偏高。但預檢時充足的計畫不會加入本輪刷取列表，且跳過的計畫無法在執行中加入，辨識後發現實際庫存不足也只會記錄提示。重新執行任務即可按實際庫存刷取。手動消耗或使用過材料與道具（例如用紅票購物、合成材料）後，建議先透過 [更新資料](./user-data-update.md) 任務或 [倉庫辨識](./tools.md#倉庫辨識) 工具同步一次，再開始任務。

建議保持勾選，除非你確定快取資料仍然準確，或想節省辨識時間。

### AUTO 代理倍率

未勾選時按單倍（1×）代理刷取；勾選後按目前理智可刷的最大倍率代理，單次刷取數量可能超過目標庫存上限。

### 啟用 ｢吃理智藥｣ / ｢吃源石｣ 勾選框

控制各計畫是否顯示對應的理智藥/源石行。關閉後所有計畫統一不使用理智藥或源石。

### 使用 48 小時內過期的理智藥

勾選後，所有計畫都會優先使用 48 小時內即將過期的理智藥（固定 2 天閾值）。未設理智藥預算的計畫也會嘗試使用臨期藥。這些計畫只有在以下情況才會被理智不足判定跳過：本次執行的任務鏈中，已有倉庫維持計畫或 ｢目標庫存｣ 模式的理智作戰未達到目標庫存而正常結束，即已嘗試用盡視窗內的臨期藥仍然打不動。按次數刷的理智作戰結束原因不唯一，不構成此證明。

### 活動期間跳過

勾選後，當檢測到有活動進行中時，跳過整個倉庫維持任務。

### 資源收集限時全天開放期間跳過

勾選後，當檢測到資源收集關卡處於限時全天開放期間時，跳過整個倉庫維持任務。

### 僅執行第一個庫存不足的計畫

勾選後，每次執行只會執行第一個庫存不足且當日可執行的計畫，日誌也只顯示到該計畫為止；該計畫補滿後，下次執行會自動接續後續計畫。當日無法執行的計畫（關卡未開放、配置無效）會被跳過。

### 按庫存達成率排序執行

勾選後，每次執行按庫存達成率從低到高排序下發計畫，缺口比例最大的計畫優先獲得理智；列表顯示順序不變，拖曳排序僅在未勾選時生效。

排序使用的是上次辨識的快取庫存資料（預檢同源）。每條計畫開始時仍會按最新庫存重算缺口：按舊資料排在前面的計畫若實際已達標，會直接跳過，不浪費理智。未辨識過的材料按 0 計，即視為缺口最大優先刷取；無效計畫（未選材料或目標為 0）排在最後。與 ｢[僅執行第一個庫存不足的計畫](#僅執行第一個庫存不足的計畫)｣ 同時開啟時，被執行的 ｢第一個｣ 即缺口比例最大的那條。
