# 更換主題

切換遊戲主介面的 UI 主題。

## 使用說明

1. 將 ｢更換主題｣ 任務新增至任務佇列。
2. 在任務設定中填寫候選主題名，即遊戲內 ｢更換主題｣ 列表中顯示的名稱（如 ｢日間｣｢夜間｣）。
3. 填寫多個主題名時，每次執行隨機選擇一個；僅填寫一個時固定切換。
4. 未填寫任何主題名時，跳過任務並在日誌中提示。

任務執行時會先回到主介面再進入主題列表尋找目標，目前頁面找不到則快速滑到列表頂部，再向下逐頁尋找。主題名依靠文字辨識比對，少數罕用字可能被誤認成字形相近的字而找不到主題（如 ｢淞｣ 被辨識成 ｢淋｣；實測遇到的誤認已內建校正）；若仍遇到，請透過 ｢問題回饋｣ 提交日誌壓縮檔，日誌中包含實際辨識結果，便於補充校正規則。

::: tip 主題被自動切回後如何換回
MAA 尚未支援的新主題切換成功後，後續任務可能因無法辨識其主介面，而觸發 ｢切回日間主題｣ 的保護機制。把本任務放在任務佇列末尾並填入原主題名，即可在所有任務結束後把主題換回來。
:::
