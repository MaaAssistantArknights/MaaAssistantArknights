# 更換主題

切換遊戲主界面的 UI 主題。

## 使用說明

1. 將 ｢更換主題｣ 任務添加到任務佇列。
2. 在任務設定中填寫候選主題名，即遊戲內 ｢更換主題｣ 列表中顯示的名稱（如 ｢日間｣｢夜間｣）。
3. 填寫多個主題名時，每次執行隨機選擇一個；僅填寫一個時固定切換。
4. 未填寫任何主題名時，跳過任務並在日誌中提示。

任務執行時會先回到主界面再進入主題列表查找目標，當前頁未找到則快速滑到列表頂部，再向下逐屏查找。主題名依靠文字識別匹配，個別不常用字可能被誤認成形近字導致未找到（如 ｢凇｣ 被認成 ｢淞｣；實測遇到的誤認已內建糾正）；若仍遇到，請透過 ｢問題回饋｣ 提交日誌壓縮包，日誌中包含實際識別結果，便於補充糾正規則。

::: tip 主題被兜底切走後換回
MAA 尚未適配的新主題切換成功後，後續任務可能因無法識別其主介面而觸發 ｢切回日間主題｣ 的兜底邏輯。把本任務放在任務佇列末尾並填入原主題名，即可在所有任務結束後把主題換回來。
:::
