# 幹員培養

幹員培養任務會按計畫列表的順序，自動把指定幹員培養到設定的**精英化**、**技能基礎等級**和**技能專精**目標。材料不足時會自動前往加工站合成、製造站生產或在憑證交易所補購，無需手動進入遊戲操作。

## 功能說明

每條計畫對應一名幹員，三類目標可以同時設定，互不衝突。

- **精英化**：逐階段晉升，每次晉升前會先把幹員升到目前階段的滿級。
- **自動補齊材料**：缺少的材料會在加工站自動合成；5 星、6 星幹員晉升精英 2 所需的雙晶片會在製造站生產，晶片助劑不足時會在憑證交易所補購。若材料配方尚未解鎖、或材料始終無法補齊，該目標記為失敗，任務會繼續處理這條計畫的其餘目標與後續計畫。
- **技能專精**：專精需要佔用訓練室並持續一段時間。一次執行最多為一名幹員啟動一次專精訓練，本次啟動訓練後，同一次執行中其餘幹員的專精目標都會被跳過（訓練室已被其他幹員佔用時，本條記為跳過）。因此要達到計畫中的專精等級，通常需要多次執行任務。
- 任務進行中會逐條輸出培養結果，結束時輸出成功、失敗與跳過的彙總；已達成目標的條目會從計畫列表中自動移除。
- 任務執行期間計畫列表不可編輯。

計畫列表中的條目可以**拖曳調整順序**，執行時會按順序逐條培養。

## 匯入計畫

除在介面中逐個新增幹員、手動設定目標外，也可以直接匯入 JSON 計畫：

1. 將計畫 JSON 複製到剪貼簿；也可以在設定中點擊「在明日方舟工具箱中線上編輯計畫」連結，在 [明日方舟工具箱](https://arkntools.app/#/material) 中線上編輯後匯出。
2. 在幹員培養設定中點擊「從剪貼簿讀取」，解析出的計畫會附加到目前列表末尾。

計畫的每個陣列項目對應一名幹員：

| 欄位            | 類型   | 必需 | 說明                                                                                                     |
| :-------------- | :----- | :--- | :------------------------------------------------------------------------------------------------------- |
| `role`          | string | 否   | 幹員職業，取值見下方清單；省略時由 `name` 自動推斷，該名稱對應多個職業時必須明確指定                     |
| `name`          | string | 是   | 幹員名，如 `阿米婭` / `Amiya`，不能為空                                                                  |
| `elite`         | int    | 否   | 精英化目標階段，`1` 或 `2`；省略 / `0` 表示不設定                                                        |
| `skill_level`   | int    | 否   | 技能基礎等級目標，`2` ~ `7`；省略 / `0` 表示不設定                                                       |
| `skill_mastery` | int[]  | 否   | 依次為技能 1 / 2 / 3 的專精目標等級，取值 `0` ~ `3`；低星幹員可以傳入 int[1]、int[2] 等長度不足 3 的陣列 |

`role` 的可取值與解包資料中的 `profession` 一致：`Pioneer`（先鋒）、`Warrior`（近衛）、`Tank`（重裝）、`Sniper`（狙擊）、`Caster`（術師）、`Medic`（醫療）、`Support`（輔助）、`Special`（特種）。
`level` 欄位保留，暫未支援。

例：

```json
[{"role": "Warrior","name":"陳","elite":2,"skill_level": 7, "skill_mastery":[0,0,3]}]
```

上例表示把近衛「陳」培養到精英 2、技能基礎等級 7 級，並把技能 3 專精到 3 級。

::: tip
欄位名區分大小寫，且不接受上表之外的欄位。任一條計畫無法解析時，本次匯入整體不生效，日誌中會給出原因。

匯入不會自動補齊前置條件。例如只設定 `skill_mastery` 而不設定 `skill_level` 時，若幹員目前技能基礎等級不足 7 級，執行時該專精目標會因前置不滿足而失敗。需要連同 `skill_level: 7` 一起設定。
:::
