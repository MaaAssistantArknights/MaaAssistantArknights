# 開始喚醒

自動啟動模擬器，自動啟動用戶端，自動進入遊戲。

自動啟動模擬器需額外設定，詳見啟動設定，且需勾選連線設定內的 `ADB 連線失敗時嘗試啟動模擬器`。

如果遊戲正停留在斷線彈窗，開始喚醒會點擊確認重新連線，然後繼續進入遊戲。

## 啟動辨識逾時

在 `開始喚醒` 的一般設定中，可填寫啟動辨識逾時秒數，預設為 `120` 秒，範圍為 `10` 至 `600` 秒。模擬器冷啟動時若黑畫面持續較久，可適度增加此值。

此設定限制啟動導覽及帳號切換導覽中，每個辨識步驟連續無法辨識畫面的等待時間，依實際經過時間計算。辨識成功後立即繼續，下一個步驟重新計時，不會固定等待填寫的時長。已辨識的載入或更新畫面不屬於連續辨識失敗，因此這不是整個啟動流程的總時限。

逾時後仍依原有邏輯回報錯誤或嘗試重新啟動遊戲。此設定僅影響開始喚醒，不會改變公開招募、基建等其他任務的等待時間。

## 帳號切換

本功能需與切換配置或定時執行一起使用，會在每次執行 `開始喚醒` 任務時都進行一次帳號切換操作。

僅支援切換至已登入的帳號，使用登入名稱進行查找，請保證輸入內容在所有已登入帳號中是唯一的。

- 範例：
  - 官服：`123****8901`，可輸入 `123****8901`、`123`、`8901`、`3****8`
  - B 服：`張三`，可輸入 `張三`、`張`、`三`
  - 繁中服：帳號為 Email，如 `ab****01@gmail.com`，建議填不含星號的明文片段，如 `01@gmail`
  - 韓服：帳號為 Email，如 `ab****01@gmail.com`，建議填不含星號的明文片段，如 `01@gmail`
