# 更新資料

::: warning 平台限制
本功能由 MAA GUI（Windows WPF 版）實作，核心（MaaCore）不包含此邏輯。使用 maa-cli、macOS 版或直接呼叫 MaaCore 的第三方 UI 無法使用本功能，需自行實作。
:::

更新資料任務用於**同步幹員名冊和倉庫庫存**的快取資料，為 [倉庫維持](./depot-maintain.md) 等功能提供準確的庫存基準。

## 功能說明

本任務包含兩個子項，可獨立勾選：

### 幹員辨識

- 辨識持有與未持有的幹員名冊，並保存潛能資料。
- 辨識結果供 [公招辨識](./tools.md#公招辨識) 顯示幹員潛能。
- 辨識完成後會顯示上次同步時間。

### 倉庫辨識

- 辨識遊戲內倉庫庫存，更新材料數量快取。
- 辨識結果供 [倉庫維持](./depot-maintain.md) 任務計算缺口。
- 也與 [小工具 - 倉庫辨識](./tools.md#倉庫辨識) 共用同一套資料，辨識完成後會顯示上次同步時間。

::: tip
本任務與 [小工具 - 倉庫辨識](./tools.md#倉庫辨識) 的區別在於：小工具需要手動進入倉庫介面操作；本任務會自動進入倉庫介面完成辨識，並可配合觸發間隔實現自動化。
:::

## 觸發間隔

可設定任務的執行頻率：

| 選項 | 說明 |
| :--- | :--- |
| 每次 | 每次執行任務佇列時都執行更新。 |
| 每天 | 每天最多執行一次，當天再次觸發時自動跳過。 |
| 每週 | 每週最多執行一次。 |

建議設為「每天」，在每天首次執行時自動同步資料，避免頻繁 OCR 影響效率。
