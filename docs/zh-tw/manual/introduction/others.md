## GPU 加速推論

使用 DirectML 呼叫 GPU 進行辨識推論加速 <sup>[PR](https://github.com/MaaAssistantArknights/MaaAssistantArknights/pull/9236)</sup>，可透過少量的 GPU 佔用降低大量的 CPU 佔用，推薦啟用。

經測試，部分顯示卡因缺少功能或效能較低，在使用本功能時會出現辨識問題。MAA 已內建了部分 GPU 黑名單 <sup>[PR1](https://github.com/MaaAssistantArknights/MaaAssistantArknights/pull/9990)[PR2](https://github.com/MaaAssistantArknights/MaaAssistantArknights/pull/12134)</sup>，若列表外的顯示卡在啟用本功能後也出現辨識問題，請發 Issue。

## 僅一次

主介面和設定中的配置變更通常會自動儲存，但以下幾種會在 MAA 重啟後重置。

- 標有 `*` 號的選項
- 標有 `（僅一次）` 的選項
- 透過右鍵點選核取方塊得到的半選開關

許多核取方塊支援右鍵點選進行半選（僅一次生效），MAA 重啟後重置。常見的應用場景包括：

- **主任務清單**：右鍵勾選某個任務為半選狀態，本次執行會執行該任務，但重啟後恢復原狀。預設右鍵為「僅一次生效」，可在 `設定` - `介面設定` - `反轉主任務右鍵點擊效果` 中切換為「僅一次跳過」（即右鍵半選的任務本次不執行）。
- **戰鬥設定**：`吃理智藥`、`吃源石` 等選項右鍵半選後僅本次生效。

## 啟動時自動切換配置

MAA 支援透過啟動參數自動切換配置，在 MAA 程序名稱後附加 `--config <配置名稱>` 即可。範例：`./MAA/MAA.exe --config 官服`。

部分符號需要轉義，參考 JSON。範例：在配置名稱為 `"官服"` 時，參數應為 `--config \"官服\"`。

## 開始前 / 結束後腳本

v4.13.0 後支援設定開始前 / 結束後腳本，可在任務前後自動執行批次檔。輸入框內需填寫批次檔即 `*.bat` 的絕對或相對路徑。

## 配置遷移

在 Windows 版本中，MAA 的所有配置都存放於 `config` 資料夾裡。遷移此資料夾即可遷移 MAA 的所有設定。

## 定時執行

在 `設定` - `定時執行` 中可設定最多 8 組定時任務。每組包含啟用開關、時間（時:分）和對應的配置。

- 定時時間到達後，MAA 會自動連接模擬器並開始執行目前配置中勾選的任務。
- 每個定時項的核取方塊支援右鍵半選（僅一次），即只在本次生效，MAA 重啟後重置。

### 強制定時啟動

勾選後會**停止目前正在執行的任務**，重新啟動遊戲並開始新任務。適用於應對遊戲每日 04:00（伺服器當地時間）的閃斷更新——在閃斷時間後強制重新啟動遊戲並重新執行任務，確保任務不會因閃斷而卡住。

如需閃斷更新後自動重連並繼續任務，請同時啟用 `開始喚醒` 任務。

### 自定義配置選擇

勾選後，每個定時項可以指定不同的配置。MAA 會在定時觸發**前兩分鐘**重新啟動並切換到對應配置，再開始執行任務。

## 更新

MAA 的更新分為兩種內容：

- **軟體版本**：主程式的介面和功能更新。
- **資源版本**：素材資料更新，包含新關卡地圖、掉落物圖示、公招幹員標籤等。軟體版本發布時通常已包含當時的最新資源。

::: tip 導航熱更
另有一種「導航熱更」，會自動觸發，用於更新主介面提示與活動關卡入口。成功後右上角會顯示提示。
:::

### 更新管道

可在 `設定` - `更新設定` 中切換更新管道：

- **正式版**：Bug 更少，新功能新主題支援更慢。新功能可能需要數週後才會支援。
- **公測版**：可能存在少量 Bug，新功能新主題支援更快。
- **內測版**：包含不穩定功能，僅供測試。請勿在其他地方討論內測版問題。

::: tip
若介面提示版本過低且最低需求版本為公測版，但檢測已是最新版本，說明該功能目前僅在公測版中提供，需等待正式版發布或切換至公測版取得。
:::

### 自動更新

在 `設定` - `更新設定` 中可選擇更新來源：

| 更新來源 | 說明 |
| :--- | :--- |
| **海外源**（GitHub） | 軟體版本從 GitHub 拉取；資源版本由 [Mirror醬](https://mirrorchyan.com/zh/projects?rid=MAA) 提供免費的更新檢測，可手動點選 `資源更新` 從 GitHub 下載。 |
| **Mirror醬** | 填寫 CDK 後支援軟體與資源自動更新，優先通過高速 CDN 下載，更穩定快速。 |

可在更新設定中開啟或關閉以下選項：

- `啟動時檢查更新`
- `定時檢查更新`（對應伺服器當地時間 04:00 / 22:00，即遊戲內每日重置時間和理智完全恢復時間）
- `自動下載更新包`：關閉後僅通過通知提示，可自行下載更新包後拖入 MAA 完成更新（見下方手動更新）。
- `自動安裝更新包`

資源更新在任務期間檢測到時，會在系統空閒時自動載入，於下次任務生效。

### 手動更新

如果自動下載失敗或網路不佳，可以手動下載更新包，然後**直接將 `.zip` 壓縮包拖入 MAA 主視窗**即可完成更新。MAA 會辨識包類型並處理：軟體更新包主要看檔名；資源更新包主要辨識是否為 GitHub 資源倉庫 zip，並解析其中的 `version.json`。

- 拖入**軟體更新包**（完整包 / OTA）：v6.8.0-beta.2 起支援。
- 拖入**資源更新包**：v6.16.5 起支援。

::: tip
僅支援從 [GitHub Releases](https://github.com/MaaAssistantArknights/MaaAssistantArknights/releases) 下載的包。[Mirror醬](https://mirrorchyan.com/zh/projects?rid=MAA) 的更新包格式不同，且為自動更新專用，**不支援拖入**。
:::

#### 軟體更新包（完整包 / OTA 增量包）

- 從 [GitHub Releases](https://github.com/MaaAssistantArknights/MaaAssistantArknights/releases) 下載對應的更新包，檔名格式需保持不變：
  - **完整包**：`MAA-<版本號>-win-<架構>.zip`，如 `MAA-v5.20.0-win-x64.zip`。
  - **OTA 增量包**：`MAAComponent-OTA-<目前版本>_<目標版本>-win-<架構>.zip`，來源版本必須與目前版本一致。
- 拖入後，MAA 會自動解壓縮並在下次重啟時套用更新。
- **完整包更新需要手動確認**：完整包會清理安裝目錄下的舊檔案（保留 `config`、`data`、`debug`、`cache`、`achievement`、`background` 等），請確保 MAA 安裝在獨立資料夾中，不要與其他檔案混放。

::: danger 完整包更新風險
如果你把 MAA 直接放在磁碟根目錄、桌面、下載目錄，或與其他程式/個人檔案混放在同一層級，完整包更新可能會誤刪同層檔案。請務必將 MAA 放在獨立資料夾內，並在更新前手動備份。
:::

::: details 不使用拖入更新的傳統方式
如果 MAA 版本過低不支援拖入更新（v6.8.0-beta.2 之前），可解壓縮完整包至**新**資料夾，再複製舊目錄的 `config` 和 `data` 資料夾以保留資料。⚠️ 請勿直接覆蓋舊資料夾，錯誤操作可能導致資源損壞。
:::

#### 資源更新包

- 從 [GitHub](https://github.com/MaaAssistantArknights/MaaResource/archive/refs/heads/main.zip) 下載資源倉庫的 zip 包（保持 GitHub 直接下載的目錄結構，例如含 `MaaResource-main/resource/...`）。
- 拖入後，MAA 會解析包內 `version.json` 判斷資源版本（不會匯入比目前更舊的包），再解壓縮合併到 `resource` 目錄並自動重載。
- 資源包為增量內容，不會刪除原有資源檔案。
- 不使用拖入時，也可手動解壓縮後直接覆蓋 `resource` 資料夾（⚠️ 增量內容，請勿刪除原資料夾）。

#### 不支援的包

如果拖入的檔案不是上述任何一種更新包（如軟體包檔名不匹配、資源包不是 GitHub zip 結構、版本不匹配等），MAA 會彈出提示告知無法辨識。

::: warning 不會完整校驗包內容
- **軟體更新包**（完整包 / OTA）：主要依據檔名匹配，**不會**校驗壓縮包內是否真為對應架構或版本。若手動改名（例如將 arm64 包改名為 x64），仍可能照常解壓縮並裝錯版本。請勿修改原始檔名。
- **資源更新包**：只檢查是否為 GitHub 直接下載的 zip 結構，並解析 `version.json`；**不會**逐一校驗包內其他資源檔案是否齊全或正確。缺少部分檔案時仍可能匯入。
:::

## 其他說明

- 首頁左側任務可以拖曳改變順序，基建換班設定中設施順序同理。
- 所有點選操作，皆為點選按鈕內隨機位置，並模擬帕松分佈（Poisson distribution，按鈕中心的點選機率最高，距離中心越遠，點選機率越低）。
- 底層演算法純 C++ 開發，並設計了多重快取技術，最大限度降低 CPU 和記憶體佔用。
- 軟體支援自動更新 ✿✿ ヽ(°▽°)ノ ✿ ，推薦非槓精的同學使用公測版，一般來說更新快且 Bug 少。（什麼 MIUI (╯‵□′)╯︵┻━┻
- 如果新版本自動下載失敗，可手動下載 OTA 壓縮檔後直接放到 MAA 目錄下，會自動更新。
