# 自動肉鴿

MAA 預設選擇傀影主題，可在 `自動肉鴿 - 肉鴿主題` 中更改目標主題。

::: warning  
所有涉及到自動戰鬥的功能都需要符合以下前提，這包括但不限於自動戰鬥和自動肉鴿。

- 至少 60 FPS 的**穩定**遊戲偵數
- 觸控模式為 Minitouch、MaaTouch 或 MuMu 觸控增強

:::

- 請在遊戲內將對應肉鴿主題置頂在終端處，雖然目前也可以自動導航，但不保證長期可用性。
- 請提前手動結束**非目標主題**的探索，確保目標主題目前可開始探索。
- 設定中可選擇主題、難度、分隊、開局幹員等。開局幹員預設僅第 1 順位，可在 `進階設定` 中啟用第 2、3 順位，三個順位的幹員職業不能相同。
- 招募只在前幾頁內翻找指定幹員，希望消耗低的幹員可能因排位靠後而找不到，屆時該位置會回退預設策略，建議將希望消耗高的幹員排在前面。
- MAA 可以使用助戰幹員開局，需先在 `一般設定 → 開局幹員` 中填寫目標幹員名稱，再在 `進階設定` 中啟用各開局幹員對應的使用助戰勾選框；每個順位均可獨立設定是否借助戰，但第 1 順位借助戰與凹直升精二互斥（凹直升精二僅支援自有幹員）。
- 在新安裝的客戶端中**首次**遊玩時，進入大地圖等介面後會出現新手教學。請在閱讀後手動將其關閉。

## 黑流樹海刷開局

黑流樹海選擇 `刷開局` 策略時，會反覆進行準備局與目標局來獲取滿意的開局，可配置以下內容：

- `期望獎勵` / `羽蛇獎勵`（後者需選擇 `襁褓羽蛇` 培育目標）：兩者中勾選的全部視為候選，目標局開局出現任意一項即滿足。
- `凹第一層實托邦`：目標局在支援頁出現期望獎勵後，按 `開局獎勵選擇優先順序` 選卡並進入第一層；第一層是實托邦就退出並保留這一局，不是就放棄這一局，重新進行準備局。需要難度 6 及以上。
- `開局獎勵選擇優先順序`：拖動調整順序，支援頁按從上到下的順序選擇在場的卡。
- `快速飛往第三層`：準備局固定用 `特勤分隊`、`穩紮穩打` 和自己的機械師開局，只招募機械師，第二層用自帶的結構性原理直接飛到第三層；機械師天賦未點滿會飛不起來，請不要勾選。

## 戰鬥策略

MAA 在肉鴿內的一切操作都是預設的策略，所有關卡戰鬥都是呼叫內建的作業檔案。當對應關卡作業不存在時會使用並不聰明的通用決策樹進行戰鬥。

詳情請查閱 [肉鴿協定](../../protocol/integrated-strategy-schema.md)。

- 支援自動辨識幹員及練度，並自動選擇較優幹員及技能。
- 支援辨識商店物品，優先購買更強力的收藏品。

## 異常檢測

- 如果任務出現問題，會自動放棄當次探索並重試。
- 戰鬥時長超過 8 分鐘會自動撤退所有地面單位，超過 10 分鐘會自動放棄該局戰鬥，避免互相刮痧耗時。

如果多次在同一個位置卡住，請提交 Issue 回饋，並附帶日誌檔案和 `debug/Roguelike` 資料夾中相關截圖。
