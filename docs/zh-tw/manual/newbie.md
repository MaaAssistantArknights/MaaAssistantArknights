# 新手上路

一句話教學！

::: info 關於本文檔
本手冊以 **Windows 版 MAA（WPF 桌面端）** 為主進行介紹。MAA Team 主要維護的就是 Windows 端的 WPF UI，maa-cli 和 macOS 版由團隊中少數開發者維護，功能可能存在差異或滯後。

部分功能（如庫存保持、定時執行、拖入壓縮包更新等）由 UI 層實作，核心（MaaCore）不包含此邏輯。使用 maa-cli、macOS 版或直接呼叫 MaaCore 的第三方 UI 時，這些功能可能不可用，需自行實作。涉及 UI 專屬功能的文檔頁面頂部會有標註。
:::

## 前置準備

:::: steps

1. 確認系統版本

   MAA 在 Windows 下僅支援 10 和 11，舊版 Windows 使用者請參閱 [常見問題](./faq.md#系統問題) 中的系統問題部分。

   非 Windows 使用者請參閱 [模擬器及設備支援](./device/)。

2. 確認模擬器支援

   查閱 [模擬器和設備支援](./device/)，確認正在使用的模擬器支援情況。

3. 下載與安裝

   查閱 [下載與安裝](./install.md)。

4. 正確設定模擬器解析度

   模擬器解析度應為橫向顯示的 `1280x720` 或 `1920x1080`；對於美服（YoStar EN）玩家，必須設定為 `1920x1080`。

::::

## 初始配置

0. 若需要使用自動偵測，請僅執行**一個**模擬器，並確保沒有其他安卓設備連接電腦。

1. 跟隨設定指引進行配置，MAA 會自動偵測正在執行的模擬器。若偵測失敗、需要多開模擬器等情況，請參閱 [連線設定](./connection.md)。

2. MAA 啟動時會自動檢查並更新遊戲資源，更新內容在系統閒置時自動載入，無需重啟即可生效。

3. 拖曳左側任務列表對任務進行排序，勾選或取消勾選核取方塊來選擇要執行的任務。點擊任務右側的齒輪可展開該任務的詳細設定。

4. Link Start!
