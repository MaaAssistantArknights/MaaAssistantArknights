# 自动肉鸽

MAA 默认选择傀影主题，可在 `自动肉鸽` - `肉鸽主题` 中更改目标主题。

::: warning  
所有涉及到自动战斗的功能都需要以下前提，这包括但不限于自动战斗和自动肉鸽。

- 至少 60 帧的**稳定**游戏帧数
- 触控模式为 Minitouch、MaaTouch 或 MuMu 触控增强

:::

- 请在游戏内将对应肉鸽主题置顶在终端处，虽然目前也可以自动导航，但不保证长期可用性。
- 请提前手动结束**非目标主题**的探索，确保目标主题当前可开始探索。
- 设置中可选择主题、难度、分队、开局干员等。开局干员默认仅第 1 顺位，可在 `高级设置` 中启用第 2、3 顺位，三个顺位的干员职业不能相同。
- 招募只在前几页内翻找指定干员，希望消耗低的干员可能因排位靠后而找不到，届时该位置会回退默认策略，建议将希望消耗高的干员排在前面。
- MAA 可以使用助战干员开局，需先在 `常规设置` → `开局干员` 中填写目标干员名，再在 `高级设置` 中启用各开局干员对应的使用助战勾选框；每个顺位均可独立设置是否借助战，但第 1 顺位借助战与凹直升精二互斥（凹直升精二仅支持自有干员）。
- 在新安装的客户端中**首次**游玩时，进入大地图等界面后会出现新手教程。请在阅读后手动将其关闭。

## 黑流树海刷开局

黑流树海选择 `刷开局` 策略时，会反复进行准备局与目标局来获取满意的开局，可配置以下内容：

- `期望奖励` / `羽蛇奖励`（后者需选择 `襁褓羽蛇` 培养目标）：两者中勾选的全部视为候选，目标局开局出现任意一项即满足。
- `凹第一层实托邦`：目标局在支援页出现期望奖励后，按 `开局奖励选择优先级` 选卡并进入第一层；第一层是实托邦就退出并保留这一局，不是就放弃这一局，重新进行准备局。需要难度 6 及以上。
- `开局奖励选择优先级`：拖动调整顺序，支援页按从上到下的顺序选择在场的卡。
- `快速飞三层`：准备局固定用 `特勤分队`、`稳扎稳打` 和自己的机械师开局，只招机械师，第二层用自带的结构性原理直接飞到第三层；机械师天赋未点满会飞不起来，请不要勾选。

## 战斗策略

MAA 在肉鸽内的一切操作都是预设的策略，所有关卡战斗都是调用内置的作业文件。当对应关卡作业不存在时会使用并不聪明的通用决策树进行战斗。

详情请查阅 [肉鸽协议](../../protocol/integrated-strategy-schema.md)。

- 支持自动识别干员及练度，并自动选择较优干员及技能。
- 支持识别商店物品，优先购买更强力的收藏品。

## 异常检测

- 如果任务出现问题，会自动放弃当次探索并重试。
- 战斗时长超过 8 分钟会自动撤退所有地面单位，超过 10 分钟会自动放弃当局战斗，避免互相刮痧耗时。

如果多次在同一个位置卡住，请提交 Issue 反馈，并附带日志和 `debug/Roguelike` 文件夹中相关截图。
