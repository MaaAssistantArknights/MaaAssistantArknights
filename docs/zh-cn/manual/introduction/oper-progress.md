# 干员培养

干员培养任务会按计划列表的顺序，自动把指定干员培养到设定的**精英化**、**技能基础等级**和**技能专精**目标。材料不足时会自动去加工站合成、制造站生产或凭证交易所补购，无需手动进入游戏操作。

## 功能说明

每条计划对应一名干员，三类目标可以同时设定，互不冲突。

- **精英化**：逐阶段晋升，每次晋升前会先把干员升到当前阶段的满级。
- **自动补齐材料**：缺失的材料会在加工站自动合成；5 星、6 星干员晋升精英 2 所需的双芯片会在制造站生产，芯片助剂不足时会在凭证交易所补购。若材料配方尚未解锁、或材料始终无法补齐，该目标记为失败，任务会继续处理这条计划的其余目标与后续计划。
- **技能专精**：专精需要占用训练室并持续一段时间。一次运行最多为一名干员启动一次专精训练，本次启动训练后，同一次运行中其余干员的专精目标都会被跳过（训练室已被其他干员占用时，本条记为跳过）。因此要达到计划中的专精等级，通常需要多次运行任务。
- 任务进行中会逐条输出培养结果，结束时输出成功、失败与跳过的汇总；已达成目标的条目会从计划列表中自动移除。
- 任务运行期间计划列表不可编辑。

计划列表中的条目可以**拖拽调整顺序**，运行时会按顺序逐条培养。

## 导入计划

除在界面中逐个添加干员、手动设定目标外，也可以直接导入 JSON 计划：

1. 将计划 JSON 复制到剪贴板；也可以在设置中点击「在明日方舟工具箱中在线编辑计划」链接，在 [明日方舟工具箱](https://arkntools.app/#/material) 中在线编辑后导出。
2. 在干员培养设置中点击「从剪贴板读取」，解析出的计划会追加到当前列表末尾。

计划的每个数组项对应一名干员：

| 字段            | 类型   | 必需 | 说明                                                                                                     |
| :-------------- | :----- | :--- | :------------------------------------------------------------------------------------------------------- |
| `role`          | string | 否   | 干员职业，取值见下方列表；省略时由 `name` 自动推断，该名字对应多个职业时必须显式指定                     |
| `name`          | string | 是   | 干员名，如 `阿米娅` / `Amiya`，不能为空                                                                  |
| `elite`         | int    | 否   | 精英化目标阶段，`1` 或 `2`；省略 / `0` 表示不设定                                                        |
| `skill_level`   | int    | 否   | 技能基础等级目标，`2` ~ `7`；省略 / `0` 表示不设定                                                       |
| `skill_mastery` | int[]  | 否   | 依次为技能 1 / 2 / 3 的专精目标等级，取值 `0` ~ `3`；低星干员可以传入 int[1]、int[2] 等长度不足 3 的数组 |

`role` 的可取值与解包数据中的 `profession` 一致：`Pioneer`（先锋）、`Warrior`（近卫）、`Tank`（重装）、`Sniper`（狙击）、`Caster`（术师）、`Medic`（医疗）、`Support`（辅助）、`Special`（特种）。
`level` 字段预留，暂未支持。

例：

```json
[{"role": "Warrior","name":"陈","elite":2,"skill_level": 7, "skill_mastery":[0,0,3]}]
```

上例表示把近卫「陈」培养到精英 2、技能基础等级 7 级，并把技能 3 专精到 3 级。

::: tip
字段名区分大小写，且不接受上表之外的字段。任一条计划无法解析时，本次导入整体不生效，日志中会给出原因。

导入不会自动补齐前置条件。例如只设定 `skill_mastery` 而不设定 `skill_level` 时，若干员当前技能基础等级不足 7 级，运行时该专精目标会因前置不满足而失败。需要连同 `skill_level: 7` 一起设定。
:::
