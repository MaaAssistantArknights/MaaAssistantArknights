# 库存保持

::: info UI 专属功能
本页功能由 UI 层实现，详见[新手上路](../newbie.md#关于本文档)中的说明。
:::

库存保持是一个**自动化刷材料到目标库存**的任务。它会根据 [仓库识别](./tools.md#仓库识别) 中缓存的库存数据，自动计算缺口并刷取指定关卡，直到材料数量达到目标值后停止。

## 工作原理

1. 任务开始时（如果勾选了「任务开始前更新库存数据」），先执行一次仓库识别，获取最新的材料库存。
2. 根据每条计划中设定的目标库存，减去当前已有数量，计算需要刷取的缺口。
3. 对有缺口的材料，自动添加对应的理智作战任务。
4. 每次关卡掉落后，实时更新库存缓存，前序计划刷出的材料会影响后续计划的缺口计算。
5. 每条计划开始前会即时判定是否需要执行：库存已达标，或按最近一场战斗上报的理智估算的当前理智低于本关卡单次进图的最低消耗、且该计划无药剂/源石手段时，直接跳过该计划（不进终端、不导航），并在日志中说明原因。临期药何时视为不可用，见「[使用 48 小时内过期的理智药](#使用-48-小时内过期的理智药)」。

::: tip 库存数据同步
库存数据是缓存值，手动刷关、合成或消耗材料后可能与实际不一致。可通过 [更新数据](./user-data-update.md) 任务或 [仓库识别](./tools.md#仓库识别) 工具同步。
:::

## 计划配置

每条计划包含以下内容：

| 配置项     | 说明                                                                     |
| :--------- | :----------------------------------------------------------------------- |
| 关卡选择   | 选择刷取的关卡。支持常规关卡、芯片本、资源关卡等，不支持「当前/上次」。  |
| 指定掉落物 | 选择目标掉落材料。每个关卡可能有多个可掉落物，请选择实际需要刷取的材料。 |
| 目标库存   | 设定该材料的目标持有数量。达到后该条计划自动完成。                       |
| 使用药剂   | 勾选后可设定使用理智药的数量。                                           |
| 使用源石   | 勾选后可设定碎源石的数量。                                               |

计划列表中的条目可以**拖拽调整顺序**。运行时会按顺序逐条执行。

::: tip 理智不足时的跳过规则
- 理智判定依据的是本次执行的任务链中最近一场进图战斗（库存保持的计划或独立理智作战）上报的理智值，并按每 6 分钟回复 1 点、不足 6 分钟按 6 分钟计算来估算当前值（不超过理智上限）。
- 设置了药剂或源石预算的计划不会被理智不足判定跳过：即使理智不够，也会进图并按预算回复理智继续作战。
- 未设预算的计划在库存已达标、或估算的当前理智低于本关卡单次进图的最低消耗且临期药不可用（判定见「使用 48 小时内过期的理智药」）时，会被直接跳过，不进图查看。
- 判定使用的是最新状态：中间计划吃药打到目标库存后，剩余的理智仍会流向后续关卡。
:::

### 预设

内置以下预设，可一键填充计划：

- **低级芯片（全职业）**：PR-A/B/C/D-1，目标各 20 个
- **高级芯片组（全职业）**：PR-A/B/C/D-2，目标各 20 个
- **龙门币**：CE-6，目标 200 万
- **采购凭证（红票）**：AP-5，目标 5000
- **技巧概要·卷3**：CA-5，目标 200

## 高级设置

### 任务开始前更新库存数据

勾选后，任务开始时会先执行一次仓库识别以获取最新库存。取消勾选则使用上次缓存的库存数据。

建议保持勾选，除非你确定缓存数据仍然准确，或想节省识别时间。

### AUTO 代理倍率

未勾选时按单倍（1×）代理刷取；勾选后按当前理智可刷的最大倍率代理，单次刷取数量可能超过目标库存上限。

### 启用「使用药剂」/「使用源石」勾选框

控制各计划是否显示对应的药剂/源石行。关闭后所有计划统一不使用药剂或源石。

### 使用 48 小时内过期的理智药

勾选后，所有计划都会优先使用 48 小时内即将过期的理智药（固定 2 天阈值）。未设药剂预算的计划也会尝试使用临期药。这些计划只有在以下情况才会被理智不足判定跳过：本次执行的任务链中，已有库存保持计划或「目标库存」模式的理智作战未达到目标库存而正常结束，即已尝试用尽窗口内的临期药仍然打不动。按次数刷的理智作战结束原因不唯一，不构成此证明。

### 活动期间跳过

勾选后，当检测到有活动进行中时，跳过整个库存保持任务。

### 资源收集限时全天开放期间跳过

勾选后，当检测到资源收集关卡处于限时全天开放期间时，跳过整个库存保持任务。
