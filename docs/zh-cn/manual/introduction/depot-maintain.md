# 库存保持

库存决策只接受本轮仓库识别的 `verified_data` 精确整数。原 `data` 显示格式仍兼容；OCR失败得到的显示0以及“万／亿／K／M”缩写换算值不会用于判定达标。仓库里未出现的材料仍是未知，而不是自动认作0；当前没有额外的未拥有道具精确读取或合成流程。

本开发版本使用独立的 `DepotMaintain` 核心任务。界面可将它加入队列，增删材料计划、启停单项并拖动调整优先级。**本地构建与实机验收是两件事；未验收的开发版本不应直接替换生产助手。**

## 执行顺序

1. 先完整运行一次新的仓库识别，确认任务成功、原生回调 `done=true`，再计算缺口。昨天的缓存只用于界面展示，不用于提前排除计划。
2. 按列表顺序计算“目标持有量 − 本轮确认库存”。未识别的数量保持未知，不能当零；已达标的目标跳过。
3. 对不足且当日开放的关卡复用理智作战与掉落识别。使用实际掉落更新本轮库存，达到目标后进入下一项；不以预计次数证明达标。
4. 自然理智不够当前关卡时，记录未补满目标并结束本轮。不跳到后面的低优先级关卡，也不执行额外刷取。
5. 所有启用目标均可核实且已达标后结束。本任务不刷额外关卡；需要继续清理智时，另加独立的理智作战任务。

执行完列表后会以本轮实际库存再次核对全部目标。后续关卡顺带掉落、补满了前面的目标时，以最终库存为准；前面的关卡未开放或曾经理智不足，不会被永久记为未完成。仍有未知库存、未补满且关卡关闭的目标时，继续禁止额外刷取。

本版本固定单倍代理，**不吃药、不用临期药、不碎源石、不购买资源**。旧配置中的恢复预算保留以便回退，但本任务不会使用它们，界面不再展示这些无效开关。其他独立任务的授权和设置不受影响。

## 每项计划

| 字段 | 作用 |
| :--- | :--- |
| 启用 | 本轮是否检查、刷取该目标 |
| 关卡 | 常规、资源或芯片关卡；须已解锁并有代理 |
| 指定掉落物 | 该关卡真实可掉落的目标材料 |
| 目标库存 | 目标持有量，不是累计消耗量或固定刷取次数 |
| 顺序 | 拖动调整，前项优先使用自然理智 |

不支持以“当前／上次关卡”作为库存目标，也不自动合成、转换芯片或购买芯片助剂。高阶合成品不能假设都有直接掉落关卡；原料和合成品也不能同时作为同一培养账单的重复需求。

刷取不足目标前还会核对本地关卡身份、自然理智成本和目标材料掉落依据。无法确认的关卡，或目标不在当前掉落资料中，会报告 `stage_unknown_no_farming`／`stage_item_not_listed_no_farming`，跳过该项而不先试刷。资料缺失**不表示该材料一定不能掉落**，但不能据此授权消耗理智。后续真实掉落补满该目标时仍按最终库存判定；否则另一关卡的理智不足信号不能掩盖这个待核实目标。

企鹅统计资料可能未列出资源关卡固定奖励，因此 CE-1至CE-6的龙门币、AP-1至AP-5的采购凭证，另按游戏数据中确认的准确关卡编号与 `stageId` 配对校验，不用宽泛前缀放行。额外刷取关卡也需要有效关卡身份和正的自然理智成本；新活动资料缺失时停止并报告，不回退到上次关卡。该检查只证明当前资料支持该路线，仍必须使用实际掉落验证数量。

### 合成依赖预览

合成依赖预览仅保留为 Core API 的诊断能力，界面不提供该选项。调用者可以给 `DepotMaintain` 参数显式指定 `dependency_preview=true`。此模式仍先执行完整的新仓库识别，然后复用本地 `item_index.json` 的一件产出配方计算材料依赖；**只报告，不进入作战、额外关卡、合成或购买**。普通库存保持不启用此模式。界面和 Core 的离线构建不代表该模式已通过游戏实机验收；自动合成尚未实现。

```json
{
  "dependency_preview": true,
  "plans": [
    { "item_id": "30013", "target": 20, "enabled": true },
    { "item_id": "30012", "target": 20, "enabled": true }
  ]
}
```

这里的目标均指**最终持有量**：20个固源岩组加20个固源岩，表示合成后两种都要保留20个。若固源岩只是合成固源岩组的中间原料，不应再把它单独添加为储备目标。相同材料的重复储备行按最大目标量合并，不累加。同一共享原料的本轮库存只分配一次；任何启用目标的保留量不用于给其他目标合成。

预览计划有 `stage` 时，表示选择直接获取该材料，即使它也有配方也不展开合成；没有 `stage` 时按配方展开，不存在配方则作为叶子材料缺口。预览**不验证选择的关卡是否真的掉落该材料**，也不据此自动刷取。费用、加工站等级／干员心情、配方解锁及双芯片制造流程尚不在该预览的验证范围。

回调状态是 `dependency_preview_ready_not_targets_met` 或 `dependency_preview_unverified`，包含本轮缺口、保护库存、预计分配库存、假设合成数量和基础材料缺口。即使预览可计算，也不代表库存达标或实际合成完成；回执的 `targets_met`、`craft_executed` 和 `farm_routes_verified` 始终为 `false`。数量未知、循环配方、溢出或超出有界深度／节点数时，清除可执行缺口建议，保留错误及待核实材料，不猜数量。

配方来自上游 ResourceUpdater 的游戏数据导出：它仅保留产出数量为1、原料为正整数且均存在于物品表的配方。Core 消费侧仍重新校验。将来接入合成时必须使用真实操作结果并重新识别库存，不能把预览账本直接写回实际库存。

## 异常与完成含义

- 仓库识别失败或数据格式异常：本任务失败，不开始刷取。
- 数量未知、关卡未开放：记录原因，可以先处理其他可确认目标，但禁止执行额外关卡。
- 无代理、导航失败、掉落无法确认或被停止：失败，不通过重新导航无限重试消耗资源。
- 原生回调确认自然理智不足：本日自然预算结束，明确记录“目标仍未补满”，不报告“全部库存达标”。
- 只有队列结束，没有有效掉落或理智不足证据：仍是待核实的异常，不推断达标。

每次掉落回调先完整校验再一次性更新库存；后面的数量格式异常不会留下前面材料的半次更新。掉落识别插件报错不会被后续成功识别覆盖，也不会因作战函数返回成功而隐去。额外关卡须收到自身的自然理智不足回调才算预算完成，不能借用前面库存目标的理智不足信号；网络上报失败本身不等于掉落识别失败。

掉落回执还必须同时匹配当前计划的准确关卡编号与原生 `stageId`；未知或其他难度的回执不能增加库存。库存任务启用独立的结算检查：掉落识别失败或账本拒绝本次回执时，在当前结算结束处禁止开始下一场，不停止整个助手、其他队列或模拟器。普通理智作战没有启用该检查，原行为保持不变。此开发改动须单独进行实机验收，不能从旧构建的测试推断已验证。

`DepotMaintainInfo` 的 `depot_verified` 记录本轮精确识别物品数；各目标记录 `count_before`／`count_after`、目标和缺口，库存高于目标时仍保留真实数量，而不是将其截为目标值。它们是当前运行证据，不会写入昨天的缓存或凭预估掉落生成数量。

界面只保留“活动期间跳过”行为选项。常规设置只显示可拖动的材料列表，按列表顺序依次刷取。每行显示“材料名称:当前数量/目标数量”，未知数量显示“--”；展开后修改关卡和目标。旧配置中的预览、默认优先级、额外关卡、资源全天开放期间跳过、仅第一项和手动关卡开关不再生效。显示库存是最近一次精确认识结果，执行仍先重新识别，不用旧缓存判断本轮达标。

## 可编辑预设

- 全职业低级芯片：8种各20个，PR-A/B/C/D-1。
- 全职业高级芯片组：8种各20个，PR-A/B/C/D-2。
- 龙门币：200万，CE-6。
- 高级作战记录：556个，LS-6。
- 技巧概要·卷3：200本，CA-5。
- 采购凭证：5000，AP-5。
- 三级通用材料：当前已核对21种，各20个。只添加最终持有量目标，不同时添加其低阶合成原料；使用已核对的较早主线常规掉落关卡，不是理智效率排行榜。可按账号已解锁关卡、代理和偏好修改，晚期主线材料不能假定已解锁。

芯片、货币、技能书和红票数量沿用上游的通用储备思路，均可修改，不代表一个干员的精确账单。高级作战记录556个来自六星精零1级到精二90级共1,111,400经验，按每本2,000经验向上取整；只统计这一品质，不重复换算其他品质库存。该升级与精英化龙门币共1,334,796，不含专精和模组费用。

上述预设**不保证任意干员完整养成**：精英化材料、技能、专精、模组和合成依赖因干员而异，需明确目标干员后另列材料清单。合成和购买不在首版范围。

三级通用材料的20个是可编辑的储备缓冲，并非游戏数据规定的单干员需求。材料种类和常规掉落来源核对[物品表导出](https://github.com/Kengxxiao/ArknightsGameData/blob/master/zh_CN/gamedata/excel/item_table.json)与同版本 MAA `resource/stages.json`。新材料出现时应重新核对，不把21种当成永久固定全集。添加预设不会自动开启任务或修改生产账号；运行时仍重新识别库存、核对关卡与真实掉落。高阶合成品不混入这个直刷预设，依赖预览也不能代替真实合成。

数据依据：本地物品索引、原上游预设，以及 [游戏数据导出](https://github.com/Kengxxiao/ArknightsGameData/blob/master/zh_CN/gamedata/excel/gamedata_const.json) 中的等级经验、升级费用和精英化费用数组。默认目标没有自动添加到生产账号计划。
