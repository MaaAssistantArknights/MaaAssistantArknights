# 库存保持

::: info UI 专属功能
本页功能由 UI 层实现，详见[新手上路](../newbie.md#关于本文档)中的说明。
:::

库存保持是一个**自动化刷材料到目标库存**的任务。它会根据 [仓库识别](./tools.md#仓库识别) 中缓存的库存数据，自动计算缺口并刷取指定关卡，直到材料数量达到目标值后停止。

## 工作原理

1. 点击 ｢Link Start!｣ 后、所有任务执行前，先根据当前缓存的库存数据和每条计划的目标库存计算缺口（下文称为预检）；库存已达标的计划会被跳过，有缺口的计划才会添加对应的理智作战任务。如果勾选了 ｢任务开始前更新库存数据｣，会在本任务的刷取子任务前追加一次仓库识别。
2. 任务执行时，追加的仓库识别（如果勾选了）会先刷新库存缓存。
3. 每个计划的理智作战开始前，会用最新的库存缓存重新计算缺口。
4. 每次关卡掉落后，实时更新库存缓存，前序计划刷出的材料会影响后续计划的缺口计算。

::: tip 库存数据同步
库存数据是缓存值，手动刷关、合成或消耗材料后可能与实际不一致。可通过 [更新数据](./user-data-update.md) 任务或 [仓库识别](./tools.md#仓库识别) 工具同步。
:::

## 计划配置

每条计划包含以下内容：

| 配置项     | 说明                                                                     |
| :--------- | :----------------------------------------------------------------------- |
| 关卡选择   | 选择刷取的关卡。支持常规关卡、芯片本、资源关卡等，不支持 ｢当前/上次｣。  |
| 指定掉落物 | 选择目标掉落材料。每个关卡可能有多个可掉落物，请选择实际需要刷取的材料。 |
| 目标库存   | 设定该材料的目标持有数量。达到后该条计划自动完成。                       |
| 使用药剂   | 勾选后可设定使用理智药的数量。                                           |
| 使用源石   | 勾选后可设定碎源石的数量。                                               |

计划列表中的条目可以**拖拽调整顺序**。运行时会按顺序逐条执行。

### 预设

内置以下预设，可一键填充计划：

- **低级芯片（全职业）**：PR-A/B/C/D-1，目标各 20 个
- **高级芯片组（全职业）**：PR-A/B/C/D-2，目标各 20 个
- **龙门币**：CE-6，目标 200 万
- **采购凭证（红票）**：AP-5，目标 5000
- **技巧概要·卷3**：CA-5，目标 200

## 高级设置

### 任务开始前更新库存数据

勾选后，任务执行时会先执行一次仓库识别以获取最新库存。取消勾选则使用上次缓存的库存数据。

建议保持勾选，除非你确定缓存数据仍然准确，或想节省识别时间。

::: warning 预检用的是旧缓存
预检发生在所有任务实际执行之前（即点击 ｢Link Start!｣ 后、开始跑任务前），用的是**上一次缓存的库存数据**，而非本次新识别的结果。即使勾选了本项，仓库识别也在预检之后才执行。因此：

- 预检时缓存数量已达标的计划会被**直接跳过**，后续仓库识别刷新缓存后**不会**重新检查这些计划。
- 只有未被跳过的计划，才会在各自作战开始时用最新缓存重新计算缺口。

如果缓存可能已过时（例如手动刷关、合成后），建议先到 ｢工具箱 → 仓库识别｣ 手动同步一次再开始任务，避免误跳过仍需刷取的材料。
:::

### AUTO 代理倍率

未勾选时按单倍（1×）代理刷取；勾选后按当前理智可刷的最大倍率代理，单次刷取数量可能超过目标库存上限。

### 启用 ｢使用药剂｣ / ｢使用源石｣ 勾选框

控制各计划是否显示对应的药剂/源石行。关闭后所有计划统一不使用药剂或源石。

### 使用 48 小时内过期的理智药

勾选后，所有计划都会优先使用 48 小时内即将过期的理智药（固定 2 天阈值）。

### 活动期间跳过

勾选后，当检测到有活动进行中时，跳过整个库存保持任务。

### 资源收集限时全天开放期间跳过

勾选后，当检测到资源收集关卡处于限时全天开放期间时，跳过整个库存保持任务。
