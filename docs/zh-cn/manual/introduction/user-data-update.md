# 更新数据

::: info UI 专属功能
本页功能由 UI 层实现，详见[新手上路](../newbie.md#关于本文档)中的说明。
:::

更新数据任务用于**同步干员名册和仓库库存**的缓存数据，为 [库存保持](./depot-maintain.md) 等功能提供准确的库存基准。

## 功能说明

本任务包含两个子项，可独立勾选：

### 干员识别

- 识别持有与未持有的干员名单，并保存潜能数据。
- 识别结果供 [公招识别](./tools.md#公招识别) 显示干员潜能。
- 识别完成后会显示上次同步时间。

### 仓库识别

- 识别游戏内仓库库存，更新材料数量缓存。
- 识别结果供 [库存保持](./depot-maintain.md) 任务计算缺口。
- 也与 [小工具 - 仓库识别](./tools.md#仓库识别) 共享同一套数据，识别完成后会显示上次同步时间。

::: tip
本任务与 [小工具 - 仓库识别](./tools.md#仓库识别) 的区别在于：小工具需要手动进入仓库界面操作；本任务会自动进入仓库界面完成识别，并可配合触发间隔实现自动化。
:::

## 触发间隔

可设置任务的执行频率：

| 选项 | 说明                                       |
| :--- | :----------------------------------------- |
| 每次 | 每次运行任务队列时都执行更新。             |
| 每天 | 每天最多执行一次，当天再次触发时自动跳过。 |
| 每周 | 每周最多执行一次。                         |

建议设为「每天」，在每天首次运行时自动同步数据，避免频繁 OCR 影响效率。
