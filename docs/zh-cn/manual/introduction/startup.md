# 开始唤醒

自动启动模拟器，自动启动客户端，自动进入游戏。

自动启动模拟器需额外设置，详见启动设置，且需勾选连接设置内的 `ADB 连接失败时尝试启动模拟器`。

如果游戏正停留在掉线弹窗（如 ｢与神经网络连接丢失｣ ），开始唤醒会点击确认重新连接，然后继续进入游戏。

## 启动识别超时

在 `开始唤醒` 的常规设置中，可填写 `启动识别超时（秒）`，默认 `120` 秒，范围为 `10` 至 `600` 秒。模拟器冷启动时黑屏较久，可适当增大此值。

此设置限制启动导航和账号切换导航中，每个识别步骤连续无法识别界面的等待时间，按实际经过的时间计算。识别成功后立即继续，下一个步骤重新计时，不会固定等待填写的时长。已识别的加载或更新画面不属于连续识别失败，因此这不是整个启动过程的总时限。

超时后仍按原有逻辑报错或尝试重启游戏。此设置仅影响开始唤醒，不改变公招、基建等其他任务的等待时间。

## 账号切换

本功能需和切换配置或定时执行一起使用，会在每次执行 `开始唤醒` 任务时都进行一次账号切换操作。

仅支持切换至已登录的账号，使用登录名进行查找，请保证输入内容在所有已登录账号唯一。

- 例子：
  - 官服：`123****8901`，可输入 `123****8901`、`123`、`8901`、`3****8`
  - B 服：`张三`，可输入 `张三`、`张`、`三`
  - 繁中服：账号为 Email，如 `ab****01@gmail.com`，建议填不含星号的明文片段，如 `01@gmail`
  - 韩服：账号为 Email，如 `ab****01@gmail.com`，建议填不含星号的明文片段，如 `01@gmail`
