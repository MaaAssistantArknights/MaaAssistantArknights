# 更换主题

切换游戏主界面的 UI 主题。

## 使用说明

1. 将 ｢更换主题｣ 任务添加到任务队列。
2. 在任务设置中填写候选主题名，即游戏内 ｢更换主题｣ 列表中显示的名称（如 ｢日间｣｢夜间｣）。
3. 填写多个主题名时，每次运行随机选择一个；仅填写一个时固定切换。
4. 未填写任何主题名时，跳过任务并在日志中提示。

任务执行时会先回到主界面再进入主题列表查找目标，当前页未找到则快速滑到列表顶部，再向下逐屏查找。主题名依靠文字识别匹配，个别不常用字可能被误认成形近字导致未找到（如 ｢凇｣ 被认成 ｢淞｣；实测遇到的误认已内置纠正）；若仍遇到，请通过 ｢问题反馈｣ 提交日志压缩包，日志中包含实际识别结果，便于补充纠正规则。

::: tip 主题被兜底切走后换回
MAA 尚未适配的新主题切换成功后，后续任务可能因无法识别其主界面而触发 ｢切回日间主题｣ 的兜底逻辑。把本任务放在任务队列末尾并填入原主题名，即可在所有任务结束后把主题换回来。
:::
