基地仕事

700字程度約2分

通常モード

交代戦略

  • 効率の高いオペレーターコンビを自動で計算し、選択します。汎用スキル／特殊スキルの組み合わせおよび施設横断のコンボに対応。手動スケジューリング不要の気軽な選択肢です
  • 作戦記録・純金・源石の欠片・SoCを自動判別し、対応するオペレーターを配置
  • ドローン用途 の選択方式に基づいて、ドローンを自動使用
  • 体力状況を判別し、残り体力が 作業体力閾値 を下回ったオペレーターを寮へ移動

施設横断の組み合わせ

以下の施設横断オペレーターコンビは、基地設定で必要に応じて有効化できます：

  • レッドパイン騎士団：必須オペレーターは フレイムテイル（昇進2）、ヴィヴィアナ（昇進2）、ワイルドメイン/アッシュロック/ファートゥース（昇進2）のうち1名以上。グラベル が計算に参加します。
  • 感知情報：必須オペレーターは ウィスパーレイン（昇進2）、ロスモンティス（昇進2）、エーベンホルツ（昇進2）。シー、ヴィルトゥオーサ、アイリス、チェルニー が計算に参加します。俗世の憂い より優先されます。
  • 俗世の憂い：必須オペレーターは マルベリー（昇進2）、ステンレス（昇進2）。チョンユエ、リィン、シー が計算に参加します。
  • アビサルハンター：必須オペレーターは グレイディーア（昇進2）、ウルピアヌス、スカジ、スペクター、アンドレアナ。アルゴリズム上の理由により、レッドパイン騎士団 と同時に選択した場合は両者は同時に交代対象になりません。

交代順序

通常モードでは、施設横断の組み合わせと体力回復の連動をサポートするため、交代順序はアルゴリズムが自動的に決定します（寮 → 発電所 → 執務室 → 制御中枢 → 製造所 → 貿易所 → 応接室 → 寮 → 加工所 → 訓練室）。施設リストは MAA が処理する施設の種類のみを決定し、リストの順序は反映されません。任意の順序で交代させたい場合は 基地シフトのカスタマイズ モードを使用してください。

補足説明

  • ドローン用途 で 貿易所-龍門幣 を選択している場合、シャマレグループ を優先して判別・使用します
  • フィアメッタの回復対象：回復対象（ピュアストリーム、クロージャ、プロヴィーザ、シャマレ、テキーラ、グレイディーア）を最大3名まで指定できます。交代時、現在の体力が最も低い対象オペレーターが フィアメッタ とともに優先的に寮へ配置されます。自動交代では シャマレ と テキーラ の007運用は実現が難しいため、この2名の選択は推奨されません。
  • 応接室は各シフト時に必ず手がかりの送付を試みます。公式（Official、およびBilibili）クライアントは2025-12-05に「重複手がかりをワンクリックで送る」機能を追加しました。該当ボタンを検出した場合、MAAは自動でクリックして重複手がかりをまとめて送信します。EN/JP/KRは約6か月後、TWは約1年後に対応予定です（TWは開発進捗により早まる可能性があります）。
  • 応接室は固定の優先順位でオペレーターを選択します（例：フォーサー、ケイパー を優先）。U-Officialの手がかり傾向スキルは無効化されます。
  • 手がかり交流を開始できない場合、シフト交代時に手がかりボード上のすべての手がかりを取り下げます。開始できる場合は一括配置（ワンクリック配置）を使用します。これは、個人の手がかり所持上限が10枚（応接室に配置済みのものを含む）で、配置済みの手がかりは重複判定に含まれないためです。事前に多くの手がかりを配置しすぎると、上限に達したのに手持ちの手がかりが互いに重複していないため一括送信もできず、新しい手がかりも獲得できず、フレンドに拾ってもらうしかありません。例えば、ボードに6種類（交流の開始には7種類必要）があり、手持ちに互いに重複しない4枚があると、新しい手がかりを受け取れず、一括送信もできません。
  • 配置済みオペレーターを寮に入れない 設定により、アイリーニ や ロゴス などが訓練に未配置の際の寮入りを防止できます（ただし、加工施設で体力不足のオペレーターも移動しなくなります）
  • 制御中枢は固定の優先順位ルールでオペレーターを選択します（製造／貿易／執務室加速、他施設の体力消費軽減、施設横断コンボの連動など。同種のボーナスは重複して占拠しません）。
  • MAA が処理する対象施設は選択可能です（デフォルトは全選択）

シフト交代

  • このモードは、まずゲーム内でプリセットシフトを設定しておく必要があります。MAA が自動で交代を行います。

基地シフトのカスタマイズ

  • ワンシート攻略の有志の方々が作成した シフト生成ツール があり、基地スケジューリング仕様書 を参考に利用できます。
  • MAA フォルダー配下の /resource/custom_infrast/ には、理論上の最大効率を目指したいくつかのシフトプランが同梱されています。参考用としてお使いください。オペレーターおよび育成度の要件が非常に高いため、直接の使用は推奨しません。
