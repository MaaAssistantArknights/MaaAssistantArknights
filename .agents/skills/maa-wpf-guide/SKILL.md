## 核对和回答

- 基线为正式版 v6.21.3，对应源码提交 `561fca9d0ab37e07256b6514fe970847f0fcafa6`。新功能、活动或关卡、模拟器兼容和更新状态会变化。有用户版本时先对照该 tag 的 XAML、ViewModel、配置或资源和对应文档。仅问当前状态时核对官方发布页和现行文档。Git 仓库里可以用 `git show <tag>:<path>` 读对应版本。
- 公开文档用于给用户步骤，同版本源码用于确认控件可见性、开关生效条件、默认值和回退行为。以对应语言本地化文件核对实际显示名，递归展开 `{key=...}`。仅有 Core 任务、序列化类型或资源条目不足以证明 WPF 有入口。
- 默认用提问语言回答。先给能操作的 UI 路径和最短步骤，再交代需要的游戏画面、区服、会消耗的资源及完成判据。答案末尾附相关官方文档或版本依据。
- 给出涉及碎石、抽卡、干员培养、材料合成、商店兑换、删除存档、强制定时或关机的步骤时，标明实际影响。遇到明确报错可另用同仓库的 `maa-wpf-troubleshoot`。
