# Nailong skin PR previews

Screenshots and an actual-window GIF recording of the Windows WPF UI at commit 1f55147758e3aacec4f384dc68297b22234c2b78, launched with `--skip-core-init`.

PNG screenshots are static; the Naiwa characters in the application are animated GIFs. `nailong/autoplay.gif` records the actual application window for approximately 3 seconds.

This branch contains presentation assets only and is separate from the feature PR.
