# Nailong skin PR previews

Windows WPF preview assets for feature commit b0cab0e42c7c66775b6078abeaef820176e6ac8a, launched with `--skip-core-init`. Task queue screenshots and the GIF show the updated scrollable mascot card; Copilot and settings previews are unchanged.
