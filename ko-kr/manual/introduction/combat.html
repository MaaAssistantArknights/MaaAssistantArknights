이성 사용

약 324 단어약 1 분

UI 전용 기능

이 페이지의 일부 기능은 UI 계층에서 구현됩니다(목표 재고, 주간 일정, 다중 작업 정렬 등). 자세한 내용은 초보자 가이드를 참고하세요.

일반 설정

  • 이성 사용의 일반 설정에있는 이성 회복제 사용 + 순오리지늄 사용과 횟수 제한 및 드롭 제한 세 가지 옵션은 하나만 만족해도 종료가 됩니다.

    • 이성 회복제 사용 은 특정 횟수의 이성 회복제를 사용해 이성을 회복합니다. (연속으로 이성 회복제 사용이 가능합니다)
    • 순오리지늄 은 특정 횟수의 순오리지늄을 사용하며, 이성 회복제가 남아있을 경우 사용되지 않습니다.
    • 횟수 제한 은 선택한 스테이지를 몇번 클리어 할 지 정합니다. (예시: 15번 클리어 후 정지)
    • 드롭 제한 은 특정 재화를 몇개 획득할 지 정합니다. (5개의 장치 획득 후 정지) 두 가지 카운트 모드를 지원합니다:
      • 드롭 수: 이번 작업 중 해당 재료의 드롭 수량을 목표로 합니다.
      • 목표 재고: 창고 인식에 저장된 재고 데이터를 참조하여, 설정 재고까지 보충합니다. 데이터 업데이트 또는 창고 인식으로 재고 데이터를 먼저 가져와야 합니다. 이 모드는 UI에서 구현됩니다(Core는 드롭 수 모드만 지원).

  • 드롭 제한과 스테이지 선택은 연관되어 있지 않습니다. 드롭 제한은 재료의 개수를 기준으로 작업을 종료하는 스위치일 뿐 재료를 지정한다고 해서 스테이지를 자동으로 설정해주는 것은 아닙니다.

  • 목표 재고 모드는 재고 유지와 시작 판정을 공유합니다: 작업 시작 시 최신 재고로 부족분을 다시 계산하여 이미 달성했으면 바로 건너뜁니다. 또한 이 큐 실행 중 이미 전투가 이성을 보고했고, 보고 시각으로 추정한 현재 이성(6분당 1점·6분 미만은 6분으로 계산, 이성 상한까지)이 이 스테이지 1회 출격에 필요한 최소 소모 미만이며, 이 작업에 회복제/오리지늄 한도가 없고 만료 임박 회복제도 소진된 경우(증명 조건은 재고 유지 · 48시간 이내 만료되는 이성 회복제 사용 참고)에도 마찬가지로 건너뜁니다. 어느 쪽이든 스테이지에 진입하지 않습니다.

  • 여러 재료의 재고 목표를 동시에 관리하려면 재고 유지 작업을 사용할 수 있습니다. 여러 계획을 순서대로 자동 파밍할 수 있습니다.

  • 순오리지늄은 이성 회복제 이후에만 판단하므로 MAA는 이성 회복제가 없는 경우에만 이성을 보충합니다. 그래서 순오리지늄을 선택한 경우, 이성 회복제의 사용 횟수를 보유하고 있는 이성 회복제보다 더 많이 설정해야 합니다!

작전 개시 (이성 사용)

  • 만약 여러분이 원하는 스테이지가 목록에 없다면 MAA에서 현재/최근을 선택한 다음 게임 내에서 수동으로 스테이지를 찾으세요. 스테이지 이름, 정보, 소모 이성이 뜨고 오른쪽 하단에 대리지휘와 시작 버튼이 표시된 화면으로 가세요.
  • 해당 화면이 아닌 경우 현재/이전은 자동으로 가장 최근에 실행한 스테이지로 이동합니다.
  • 또는 작업 설정 - 이성 사용 - 고급 설정에서 스테이지 코드 수동 입력을 체크해 스테이지 코드를 직접 입력할 수 있습니다. 현재 내비게이션할 수 있는 스테이지는 다음과 같습니다:

    • 모든 메인 스토리 스테이지. 스테이지 코드 끝에 -NORMAL 또는 -HARD를 추가해 난이도를 전환할 수 있습니다 (10-14장은 표준/재앙, 15장 이후는 일반/험지).

    • 용문폐 혹은 작전 기록의 5/6스테이지는 CE-6/LS-6를 입력해야 합니다. MAA는 6스테이지가 대리 지휘가 불가능할 경우 자동으로 5스테이지로 전환합니다.

    • 스킬 북, 구매 증명서, 카본 부품 5스테이지는 CA-5/AP-5/SK-5를 입력해야 합니다.

    • 모든 칩 스테이지. 완전한 스테이지 코드를 입력해야 합니다. 예: PR-A-1.

    • 섬멸 모드는 다음 값을 지원합니다：

      • 이번 섬멸 작전：Annihilation
      • 체르노보그：Chernobog@Annihilation
      • 용문 외곽：LungmenOutskirts@Annihilation
      • 용문 시내：LungmenDowntown@Annihilation

    • 상시 개방 이벤트의 경우 OF-1/OF-F3 와 같이 입력합니다.

    • 현재 개방된 사이드 스토리 이벤트의 세 개의 스테이지입니다. API에서 업데이트를 자동으로 다운로드 한 후 화면 하단에 표시됩니다.

    • 재개방된 사이드 스토리 이벤트. SSReopen-<스테이지 접두사>를 입력하면 XX-1~XX-9 스테이지를 한 번에 완료할 수 있습니다. 예: SSReopen-IC.

예시 화면

섬멸 모드

  • MAA는 터미널 홈 화면 오른쪽 상단의 섬멸 버튼을 통해 이동합니다. 선택한 섬멸 작전이 전권 위임 상태이며 PRTS 섬멸 작전 대리권을 충분히 보유하고 있어야 합니다.
  • 해당 작전에서 400킬을 달성한 경우에만 자동 섬멸 기능 사용을 권장합니다.
  • 내비게이션 중 섬멸 입구를 찾지 못하면 이번 주 섬멸이 완료된 것으로 보고 작업을 바로 종료합니다(실패로 간주하지 않음).
  • 내비게이션 중 전권 위임(소탕) 사용 가능 여부를 확인합니다. 사용할 수 없으면 작업이 실패하고 종료됩니다.
  • 실행 중에는 소탕권이 충분한지 지속적으로 확인하지 않습니다. 중간에 소탕권이 부족하면 이후 일반 대리로 돌아가 소요 시간이 크게 늘어날 수 있습니다.
  • 정산 시 이번 주 합성옥 진행도(예: 1800 / 1800)를 인식하며, 주간 상한에 도달하면 자동 정지합니다.
  • 섬멸은 상시 스테이지입니다. 스테이지 선택 / 대체 스테이지에서 선택되면 이후 대체 스테이지는 계속 인식·실행되지 않습니다.
  • 섬멸 드롭은 펭귄 물류 및 일도류에 업로드되지 않습니다.
  • 섬멸을 먼저 돌리려면 섬멸만 선택한 이성 사용 작업을 따로 추가한 뒤, 기존 이성 사용 작업 위로 드래그하세요. 고급 설정에서 주간 일정을 켜고 월요일만 체크하면 월요일에만 실행됩니다.

고급 설정

대체 스테이지

대체 스테이지는 해당 일자의 개방 여부에 따라 실제 전투에 사용될 스테이지를 결정합니다. 즉, 열려 있는 스테이지 중 첫 번째 것을 선택하여 전투를 수행합니다.
이 기능은 일정표와 유사하며, 선택한 스테이지가 실패했을 경우를 대비한 백업 스테이지로 작동하지 않습니다.

예: 대체 단계가 용문폐-6/5, 1-7 및 경험치-6/5 로 설정되어 있는 경우:

  • 당일 용문폐-6/5가 개방되어 있다면 해당 스테이지로 진입하며, 1-7 및 경험치-6/5는 실행되지 않습니다. 이때 플레이어가 용문폐-6/5 대리를 해제한 경우 작업은 실패합니다.
  • 당일 용문폐-6/5가 개방되어 있지 않다면 1-7으로 진입하며, 경험치-6/5는 실행되지 않습니다. 이때 1-7 대리를 해제한 경우에도 작업은 실패합니다.
  • 1-7은 상시 개방된 스테이지이므로, 그 앞에 위치한 경험치-6/5는 절대 선택되지 않습니다.
  • 마찬가지로 대체 목록에서 섬멸 등 상시 스테이지가 선택되면 이후 스테이지도 계속 인식되지 않습니다.

주간 일정

  • 작업 설정 - 이성 사용 - 고급 설정에서 활성화합니다. 이 기능은 UI에서 구현됩니다.
  • 활성화 후 일요일~토요일 중 어떤 게임 내 요일에 해당 이성 사용 작업을 실행할지 체크할 수 있습니다.
  • 요일은 게임 내 시간(각 서버 시간대 + 매일 4:00 초기화)으로 계산되며, 기기 달력 요일이 아닙니다. 예: CN 서버 기준 현지 3:59는 전날로 계산됩니다.
  • 작업 시작 시: 주간 일정이 켜져 있고 당일이 체크되지 않으면 해당 이성 사용 작업은 건너뜁니다(로그에 작업 건너뜀 표시, 실패로 간주하지 않음). 이후 작업은 계속 실행됩니다.
  • 주간 일정을 사용하지 않으면 매일 해당 작업을 시도합니다.
  • 주간 일정을 켜면 「미개방 스테이지 숨기기」가 꺼지고 비활성화됩니다.
  • 전형적인 사용법: 섬멸만 선택한 이성 사용 작업을 따로 추가하고, 주간 일정에서 월요일만 체크하면 월요일에만 실행됩니다. 자세한 내용은 위 섬멸 모드를 참고하세요.

연속 전투 횟수

MAA는 사용자가 설정한 연속 전투 횟수에 따라 전투를 진행합니다.

  • AUTO (0):

    • 연속 전투 횟수를 자동 선택: 남은 횟수(스테이지가 지원하는 최대치까지)에 따라 조정합니다. 이성 회복제 사용 시 초과를 막기 위해 사용량을 자동으로 줄이며, 오리지늄은 설정된 횟수에 따라 1개씩 사용합니다.
    • 해당 배율의 1회분 이성이 부족할 때, 설정에 따라 이성을 회복(회복제 우선, 그 다음 오리지늄)하여 채웁니다. 설정이 없거나 모두 소진된 경우 작업을 종료합니다.

  • 숫자 모드 (중국 서버 1~10, 해외 서버 1~6):

    • 설정된 횟수에 따라 연속 전투를 진행합니다.
    • 설정된 배율의 1회분 이성이 부족한 경우(예: 5회분만 가능하지만 6배로 설정), 설정에 따라 이성을 회복(회복제 우선, 그 다음 오리지늄)하여 채웁니다. 설정이 없거나 모두 소진된 경우 작업을 종료합니다.

  • 비활성 모드 (-1):

    • 게임 내 연속 전투 횟수를 조정하지 않습니다.
    • 현재 게임 내 배율의 1회분 이성이 부족한 경우, 설정에 따라 이성을 회복(회복제 우선, 그 다음 오리지늄)하여 채웁니다. 설정이 없거나 모두 소진된 경우 작업을 종료합니다.

지정된 횟수

MAA는 지정된 횟수까지 전투를 수행합니다. 실제 전투 횟수는 대리 배율 단위로 내림 정렬됩니다: floor(지정 횟수 / 대리 배율) × 대리 배율. 지정 횟수를 채우기 위해 한 번의 대리보다 적은 잔여 횟수를 따로 쪼개지 않습니다(AUTO 제외, 아래 참고).

예: 현재 이성 100, 스테이지 소모 6, 스테이지 최대 대리 배율 10

  • 지정 횟수 12, 대리 배율 5: 시작 행동 2회 × 5배 = 10회 전투(floor(12 / 5) × 5 = 10), 소모 이성 10 × 6 = 60. 다시 5배를 하면 15회가 되어 12를 초과하므로 10회에서 종료.
  • 지정 횟수 12, 대리 배율 AUTO: 먼저 「남은 횟수」와 「현재 사용 가능한 최대 배율」 중 작은 값을 취해 10배로 10회 진행; 남은 2회는 2배로 처리하여 합계 12회, 소모 이성 12 × 6 = 72.
