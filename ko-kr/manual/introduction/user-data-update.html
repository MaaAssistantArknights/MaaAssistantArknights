데이터 업데이트

약 38 단어1분 미만

UI 전용 기능

이 페이지의 기능은 UI 계층에서 구현됩니다. 자세한 내용은 초보자 가이드를 참고하세요.

데이터 업데이트 작업은 오퍼레이터 명부와 창고 재고 캐시 데이터를 동기화하여, 재고 유지 등의 기능에 정확한 재고 기준을 제공합니다.

기능 설명

이 작업에는 다음 두 가지 하위 항목이 포함되며, 각각 독립적으로 체크할 수 있습니다:

오퍼레이터 인식

  • 보유 및 미보유 오퍼레이터 명부를 인식하고, 잠재능력 데이터를 저장합니다.
  • 인식 결과는 공개 채용 인식에서 오퍼레이터 잠재능력을 표시하는 데 사용됩니다.
  • 인식 완료 후 마지막 동기화 시간이 표시됩니다.

창고 인식

  • 게임 내 창고 재고를 인식하고, 재료 수량 캐시를 업데이트합니다.
  • 인식 결과는 재고 유지 작업의 부족분 계산에 사용됩니다.
  • 도구 - 창고 인식과 동일한 데이터를 공유합니다. 인식 완료 후 마지막 동기화 시간이 표시됩니다.

팁

이 작업과 도구 - 창고 인식의 차이: 도구 버전은 창고 화면으로 수동 이동이 필요하지만, 이 작업은 자동으로 창고 화면으로 이동하여 인식을 완료하며, 트리거 간격과 조합하여 자동화할 수 있습니다.

트리거 간격

작업의 실행 빈도를 설정할 수 있습니다:

옵션설명
매번작업 대기열 실행마다 업데이트를 실행합니다.
매일하루에 최대 1회 실행. 당일 재차 트리거 시 자동으로 건너뜁니다.
매주일주일에 최대 1회 실행합니다.

「매일」로 설정을 권장합니다. 매일 첫 실행 시 자동으로 데이터를 동기화하여, 잦은 OCR로 인한 효율 저하를 방지합니다.
