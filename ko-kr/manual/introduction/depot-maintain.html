재고 유지

약 104 단어1분 미만

UI 전용 기능

이 페이지의 기능은 UI 계층에서 구현됩니다. 자세한 내용은 초보자 가이드를 참고하세요.

재고 유지는 재료를 목표 재고량까지 자동으로 파밍하는 작업입니다. 창고 인식에서 캐시된 재고 데이터를 기반으로 부족분을 계산하고, 지정 스테이지를 파밍하여 목표량에 도달하면 중지합니다.

작동 방식

  1. 작업 시작 시(「작업 시작 전 재고 데이터 업데이트」에 체크한 경우) 먼저 창고 인식을 수행하여 최신 재고를 가져옵니다.
  2. 각 계획의 목표 재고에서 현재 보유 수량을 빼서 파밍해야 할 부족분을 계산합니다.
  3. 부족한 재료에 대해 해당 이성 작전 작업을 자동으로 추가합니다.
  4. 각 스테이지 드롭 후 재고 캐시를 실시간으로 업데이트합니다. 이전 계획에서 파밍한 재료가 이후 계획의 부족분 계산에 영향을 줍니다.
  5. 각 계획 시작 직전 실행 여부를 판정합니다: 이미 목표 재고에 도달했거나, 최근 전투가 보고한 이성으로 추정한 현재 이성이 이 스테이지 1회 출격에 필요한 최소 소모 미만이고 이 계획에 회복제/오리지늄 수단이 없는 경우 해당 계획을 건너뜁니다(터미널 열지 않음, 이동하지 않음). 이유는 로그에 표시됩니다. 만료 임박 회복제를 언제 사용 불가로 보는지는 「48시간 이내 만료되는 이성 회복제 사용」을 참고하세요.

재고 데이터 동기화

재고 데이터는 캐시 값이며, 수동 파밍, 합성, 재료 사용 후 실제와 다를 수 있습니다. 데이터 업데이트 작업이나 창고 인식 도구로 동기화할 수 있습니다.

계획 설정

각 계획에는 다음 내용이 포함됩니다:

설정 항목설명
스테이지 선택파밍할 스테이지를 선택합니다. 일반 스테이지, 칩 스테이지, 자원 스테이지 등을 지원합니다. 「현재/이전」은 지원하지 않습니다.
드롭 재료 지정목표 드롭 재료를 선택합니다. 각 스테이지에는 여러 드롭 재료가 있을 수 있으며, 실제로 파밍할 재료를 선택하세요.
목표 재고해당 재료의 목표 보유 수량을 설정합니다. 달성 후 이 계획은 자동으로 완료됩니다.
이성 회복제 사용체크하면 이성 회복제 사용 수량을 설정할 수 있습니다.
순오리지늄 사용체크하면 순오리지늄 사용 수량을 설정할 수 있습니다.

계획 목록의 항목은 드래그하여 순서를 변경할 수 있습니다. 실행 시 순서대로 처리됩니다.

이성 부족 시 건너뛰기 규칙

  • 이성 판정은 이 큐 실행 중 실제로 출격한 최근 전투(재고 유지 계획 또는 단독 이성 작전)가 보고한 이성 값을 기준으로, 6분당 1점·6분 미만은 6분으로 계산하여 현재 값을 추정합니다(이성 상한을 넘지 않음).
  • 이성 회복제 또는 오리지늄 한도를 설정한 계획은 이성 부족으로 건너뛰어지지 않습니다. 이성이 부족해도 출격하여 한도 범위 내에서 이성을 회복하며 전투를 계속합니다.
  • 한도를 설정하지 않은 계획은, 이미 목표 재고에 도달했거나 추정한 현재 이성이 이 스테이지 1회 출격에 필요한 최소 소모 미만이고 만료 임박 회복제도 사용 불가인 경우(판정은 「48시간 이내 만료되는 이성 회복제 사용」 참고) 출격하지 않고 바로 건너뜁니다.
  • 판정은 항상 최신 상태를 사용합니다: 중간 계획이 회복제로 이성을 회복해 목표 재고에 도달한 후에도, 남은 이성은 이후 계획에 계속 사용됩니다. :::

프리셋

다음 프리셋이 내장되어 있으며, 원클릭으로 계획을 채울 수 있습니다:

  • 저급 칩(전 직업): PR-A/B/C/D-1, 목표 각 20개
  • 고급 칩 세트(전 직업): PR-A/B/C/D-2, 목표 각 20개
  • 용문폐: CE-6, 목표 200만
  • 구매 증명(빨간 티켓): AP-5, 목표 5000
  • 스킬개론 제3권: CA-5, 목표 200

고급 설정

작업 시작 전 재고 데이터 업데이트

체크하면 작업 시작 시 창고 인식을 수행하여 최신 재고를 가져옵니다. 체크 해제 시 이전에 캐시된 재고 데이터를 사용합니다.

정확도를 중시한다면 체크를 권장합니다. 캐시가 정확하거나 인식 시간을 절약하려면 체크를 해제하세요.

AUTO 대리 배율

체크 해제 시 단배(1×) 대리로 파밍합니다. 체크 시 현재 이성으로 파밍 가능한 최대 배율로 대리하며, 1회 파밍으로 목표 재고를 초과할 수 있습니다.

「이성 회복제 사용」/「순오리지늄 사용」 체크박스 활성화

각 계획에서 해당 회복제/오리지늄 행을 표시할지를 제어합니다. 비활성화하면 모든 계획에서 회복제나 오리지늄이 일괄적으로 사용되지 않습니다.

48시간 이내 만료되는 이성 회복제 사용

체크하면 모든 계획에서 48시간 이내 만료되는 이성 회복제(고정 2일 임계값)를 우선적으로 사용합니다. 이성 회복제 한도를 설정하지 않은 계획도 만료 임박 회복제 사용을 시도합니다. 이러한 계획이 이성 부족으로 건너뛰어지는 것은 다음 경우뿐입니다: 이 큐 실행 중 재고 유지 계획 또는 「목표 재고」 모드의 이성 작전이 목표 재고에 도달하지 못한 채 정상 종료한 경우, 즉 이 창 내의 만료 임박 회복제를 모두 사용해도 여전히 전투할 수 없었던 경우입니다. 횟수 지정 이성 작전은 종료 이유가 유일하지 않으므로 이 증거가 되지 않습니다.

이벤트 기간 중 건너뛰기

체크하면 이벤트 진행 중으로 감지된 경우, 재고 유지 작업 전체를 건너뜁니다.

자원 수집 한정 전일 개방 기간 중 건너뛰기

체크하면 자원 수집 스테이지가 한정 전일 개방 기간 중으로 감지된 경우, 재고 유지 작업 전체를 건너뜁니다.
